# M2 通俗简报

**验收完成。核心结论：图片前端可以通过真正微调学得更好，但目前“先估几何、再交给固定判别器”的方案明显落后于直接看图分类。**

M2 想回答：能否保留一个已经学好的几何判别器，只训练前面的看图模块，就处理好组合变化？

| 方案 | 三步同时答对的比例 |
|---|---:|
| 冻结看图骨干，只训练几何输出层 | 15.3%–18.2% |
| 真正微调看图骨干，再接同一个固定判别器 | 34.2%–45.5% |
| 直接用真实几何输入固定判别器 | 79.4% |
| 直接训练图片分类模型 | 89.3%–91.7% |

真正微调提升了 18.8–27.3 个百分点，三个种子的配对区间均高于零。旧的“解冻没有效果、接口不可学、容量已经被排除”说法均撤回。当前证据支持“适配有效，但模块化方案未体现性能优势”；不能推广成所有模块化方法都无效。

另外发现原始 692 条记录中有 7 条重复组合。最终结论使用去重后的 685 个组合、351 个父场景，去重未改变主要方向。
