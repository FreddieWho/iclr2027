### 1. E7：比较的是哪些模型、哪些翻转

- `experiments/last15h/e7_v3.py:319–330` 用 17 点扫描，误差取 `same[0]`，即**第一个**同向翻转；`l007_diagnostic.py:214–222` 等取距 oracle **最近**的同向翻转。共享函数并不意味着共享匹配口径。多次模型翻转时两者可以不同；本轮未重建所有 E7 权重轨迹，实际影响大小 **NOT_RUN**。这不直接改变 E7 的网格积分指标。
- `e7_v3.py:127–133` 的 E7 flipmine 从 pool 抽取最多 `4×256=1024` 个状态；r04b／新种子使用全部 **1534** 个 flips（`r04b_methods.py:96,179–181`；seed manifest）。E7 JSON 的 `n_flip_states=1534` 来自 pool 总长（`:349–350`），不是实际训练计数。故 E7 与 r04b 的基线不是逐字相同；“数值同量级”不能验证 checkpoint／配方一致。
- **BAN 对照缺陷：** `e7_v3.py:199` 明确跳过 BAN teacher 的 flip loss，teacher 实际仅 clean 训练；`:279–295` 再用该 teacher 对 clean／flip 的软预测训练 student。这不是从 flipmine teacher 自蒸馏。温度仅软化 teacher、student 用普通 BCE，也应明确标作该特定变体，而非完整温度蒸馏机制证伪。
- flipmix 两臂替换 flip 监督，未在同一 flipmine 基础上加标签（`:125–141,198–211`）；其阴性是特定数据配方比较。斜率正则还有 bracket 外惩罚等同步变化，不是只改变斜率的单变量干预。
- `evaluate` 的“积分”实际是含端点的 17 点错分率均值（`:323`），不是连续路径积分。粗网格对窄错误区间可能漏检；二分只精化已发现的翻转，不能补回漏掉的翻转。
- 现存 12 个结果 JSON 的汇总与记分牌大体吻合。保留“这些配置没有五种子一致获胜”；删除“监督侧死”“瓶颈不在监督”等机制级外推。`12×5=60` 是臂×种子数；BAN 多训练一次 student，当前实现实际为 **65 次 300-epoch 网络拟合**，不含历史作废重跑。

### 2. L007：统计实现与可解释范围

- `l007_diagnostic.py:70–73` 的两次 `argsort` 给相同数值任意不同秩，不是通常的并列平均秩 Spearman；常量输入也可能产生伪相关。相同模式出现在 grazing `:46–47`、kink `:52–53`、seedvariance `:48–49`、lockin `:54–55`。原先 `n<3` 修复仍未解决此问题。
- `:81–107,236–256` 做的是固定特征、线性 ridge、按 parent 分组的五折预测。分组方向正确；CV-R²≤0 只说明这个估计器／特征集合在这个条件样本上没有预测收益，不能排除非线性效应、交互或全部输入几何。
- `hyper_dist=|logit|/||w||` 确实是输出邻接量（`:140–142,209`），且分母在同一模型中为常数。`min_abs_logit` 是 oracle 邻域内的最小 logit 模长，它与翻转距离相关但**不是一般意义上的数学等价量**：斜率、非单调性、窗口截断均会改变关系。应写“目标邻接预测量，不足以解释机制”。
- JSON 仍是 `criterion_met=true / representation-side signal`，报告却已经合理地撤销该解释。需给机器可读结果增加“字面判据触发／科学解释不成立”的区分，保留原回执，不静默改历史值。
- “miss logistic AUC”只在 docstring 提到，实际 `main` 没有计算；不能把它计作完成。报告中的附加消融不在此脚本的主流程里，本轮未独立复算其全部值。

### 3. 掠射角：路径带宽不是法向位移

`l007_grazing.py:54–63,131–143` 实现了所写的 `w_t/a`，其中 `w_t` 是 **t 轴上的** ±k logit 带宽。局部线性时：

\[
w_t\approx\frac{2k}{|\nabla f\cdot e|}
=\frac{2k}{\|\nabla f\|\,\|e\|\,a},\qquad
\frac{w_t}{a}\approx\frac{2k}{\|\nabla f\|\,\|e\|\,a^2}.
\]

角度已包含在 `w_t` 中，再除一次 a 不是“相同法向误差经过掠射后被放大一次”的检验；后者还需定义并测量法向偏移。原始几何预测的符号和尺度不能由当前相关性否定。

数值复算维持 `woa` 相关约 **0.118 / −0.063 / −0.101**，但有效 n 是 **118 / 100 / 94**，不是 summary 的非 miss n=123/122/106：没有达到 ±k 的路径又被排除一次。补报这个选择过程。`k=1` 不可达时改用 `k=2` 也不能救回同一两侧均不可达的情况。这里应降级结论，无需把修正公式包装成新的机制线。

### 4. kink：并列秩、缺失和判决分支

| seed | 原 kink-count 相关 | 正确 Spearman | kink-dist 有效 n／非 miss n |
|---|---:|---:|---:|
| 11 | −0.2192 | **−0.22770** | 113 / 123 |
| 23 | −0.2890 | **−0.30024** | 117 / 122 |
| 47 | −0.2787 | **−0.29018** | 97 / 106 |

- 三种子一起达到 ≤−0.3 仍为 false；不能把一个种子刚越线改写成机制成立。
- docstring `l007_kink.py:15–17` 写“成功≥0.3、两项<0.2才判死”，但 `:174–176` 把所有未成功情形判成 `spectral-bias closed`。当前计数相关本就在灰区，**失败分支不符合自身判据**。
- `:114–123` 数的是发生至少一次模式变化的**网格区间数**，不是精确断点数；同一区间多次变化会被合并。最缺 kink 的路径被设成 NaN 并从 kink-dist 相关排除。`:154–156` 又用 oracle 邻域有 kink 的条件筛选 `theta_on_kink_rate`，分母与“所有命中路径”不同。

### 5. 种子方差：0.41 是原始条件相关，不是残差相关

- `l007_seedvariance.py:129–141` 计算的是不同配对共同非 miss 行上的原始 `|terr|` 秩相关，没有 residualization。复算 **0.40969**，原数基本正确；28 对相关共享八个模型和路径，不能当作 28 个独立重复。
- 200 行实际只有 **100 个 parent**；`n01_brackets.py:49–68` 可以为同一 parent 生成 AB、CD 两条路径。路径统计的不确定性至少应按 parent 聚类，不可按 200 个独立场景计算。
- 八种子全部命中且 ensemble 命中的共同集合只有 **46 条**：其单种子平均 `|terr|=0.178356`，ensemble `0.155200`，相对改善 **12.983%**。原非配对人群为约 8.3%。这是选择敏感性诊断，仍低于原 15% 线；46 条幸存者也不能代表全部路径。
- 八种子从未命中的路径有 **28 条**；命中 1–7 个种子的还有 126 条。`nanvar(|terr|)` 没有处理这一缺失机制、signed error、路径／种子交互和每条路径可用种子数差异，不能称为完整 bias–variance 分解。
- 已报告的路径内方差 0.007768、路径均值间方差 0.010876 也没有给出“噪声占主导”的方差比例证明。ensemble 的“平均 logit 后求根”不是“平均各根”，收益小既可能来自共享偏差，也可能来自选择、异方差和非线性，不能反推噪声为主。
- 八组 `l007_seed/model.pt` 与 `l007_wave/ckpt_300.pt` 的参数已逐项核实完全相等；这部分重复训练一致性 **通过**。

### 6. P1：锁定统计量与文字契约不同

`l007_lockin.py:142–149` 存在三项实质偏差：

1. 容差为每个种子 `max(0.03, 0.2×最终误差均值)`，不是每条路径自己的 `max(0.03,0.2×最终误差)`。
2. `all(... for u ... for i ...)` 寻找**所有最终命中路径共同满足条件的最早时刻**，相当于最晚路径主导的整体稳定时刻；没有先计算每条路径锁定，再取中位数。
3. 中间某检查点 miss 被 `not isfinite(...)` 当作通过，可能把失去根误认为没有离开容差带；这一错误可推早，不能笼统说所有偏差都推晚。

`:177–179` 又以“至少六个种子有锁定值且总体中位数达标”替代“至少六个种子各自满足早锁条件”；`:130–141` 的收敛参照只计算 clean BCE，漏了训练中的 flip BCE。最终 checkpoint 必然能与自己一致，300 是观察窗口终点，未证明训练真正收敛。

因此 **287.5 是八个整体稳定时刻的中位数**，不能用作典型路径的锁定时刻。持续到终点的定义本身是可用操作定义，但容易受末端波动、25-epoch 分辨率和窗口终点影响。原 per-checkpoint 排名相关可以作为描述性证据保留，不能宣布关键期不存在。修正后的逐路径结果 **NOT_RUN**，现存 JSON 没有足够逐路径时序直接重算。

### 7. P2：k 的含义、代理目标与权重

- **k=6 是候选个数，不是每次删除六个场景。** `l007_loo.py:122–135` 每次传 `{s}`，实际每次删 **1/512** 场景及其 flips。36 是 3种子×(6候选+6随机) 的单删干预次数；`:120` 每种子还重新训练 baseline，总计 **39 次×300 epoch**。同时删六个／冗余群组的实验 **NOT_RUN**。
- `l007_tracin.py:127–144` 把每个 clean／flip 的裸梯度等权相加；实际目标是 `mean(clean BCE)+mean(flip BCE)`，状态权重分别 **1/512、1/1534**。省略这两个不等分母不能用整体常数抵消，改变 scene 排名。若要近似“整场景删除”，还要注明删除后的两组重新归一化效应。
- 代理窗口中心是 33 点网格的首次翻转左端 `tg[chg[0]]`（`:85–103`），可比精化的 t_star 左偏约 1/32；邻域 BCE 也同时测置信度、斜率和错分状态，不能直接视为位置损失。使用七个 checkpoint 的梯度点积作为筛选启发式是合理的，作为 Adam 下的精确删除影响则不成立：没有使用其逐坐标预条件和优化器状态。
- 排名按聚合影响的**绝对值**（`:145`），允许有益点和有害点混入；随后要求删除效应跨种子同号，会额外拒绝存在真实但异号影响的情形。先对路径／状态求平均也可能抵消局部大效应。
- 0.0066/0.0239/0.0024 的 top 中位绝对变化与报告基本相符，但 s2002 不是“千分之几”；不能把所有种子概括为几乎不动。效应是两组不同幸存路径上的 mean|terr| 差，不是同一路径根位移。
- **同 seed 基线并非相同终态：** LOO／PIN 的 s2001–2003 基线为 0.1670/0.1541/0.1795，新种子汇总为 0.1548/0.1609/0.1691；s2003 miss 为 0.415 对 0.490。代码导入 `n01_brackets.py:18` 会把线程从 4 改为 2，本轮已直接核实；seedtrain／wave 训练为 4 线程。这是具体运行环境差异，但本轮没有重训，**未证明它是数值差异的唯一原因**。组内配对 baseline 的存在仍有价值，不能抹去全部 LOO 结果。

### 8. P3：评估数据进入训练，sham 不等价

- `l007_pin.py:60–63,88–109` 从 eval_202 的目标路径取 40 个邻域状态并 oracle 标注；`:140–151` 明确把它们加入 clean 训练。该行为直接违反本次提示中的“训练只用 train_101”。标成 dev 定向探针也不能宣称 train-only 泛化阴性。
- 最近／最远场景同样由 eval 路径定义（`:65–84`）。允许在 dev 上做定向机制筛选与把 dev 派生样本用于训练是不同问题；前者也只能称定向探索，不能计作独立评价。
- B1 的矩阵维度与集合不交断言在 `:81–84,114–116` 已修，未发现该旧 bug 原样残留。但最近／最远筛选并未匹配标签、flip 数、margin、梯度量或被移除的训练权重。删除远点会改变数据分布和所有保留点的相对权重。
- A 是插入、C 是删除，本就不是等剂量对照；“C 动了”表示这个 sham 不是中性干预，不能把 A/B 的结果归为纯噪声。
- 选择问题已在现有数中可见：s2004 A 的条件误差 **0.1831→0.1455（−20.5%）**，同时 miss **0.390→0.495（+10.5pp）**。不能直接称总体精度改善。s2001 A 的误差 −10% 同时 miss +4.5pp。没有逐路径配对输出，真实位移与命中集合变化无法拆开。
- “A 2/4、C 0/4”的计数可以保留；“钉位死”必须撤销，改为“当前设计未提供可解释、符合 train-only 契约的判别”。

### 9. P5：唯一弱阳性已被完整目标复算否定

- `l007_connectivity.py:186–190` 把 raw X 送入激活匹配；实际模型用标准化 X（`common.py:36–45`）。本轮 r04b11 首层激活开关约 **7.31%** 在 raw／标准化输入下不同。
- `:169–175` 的 barrier 只用 clean BCE；flipmine 的实际目标还包括等权的 mean flip BCE。使用现存 r04b11 mining 状态、冻结模型和相同九个 α，复算如下：

| r04b11–r04b23 的贪心对齐方式 | clean 相对 barrier | 完整 clean+flip 相对 barrier |
|---|---:|---:|
| 原始 raw 输入匹配 | **0.8619%** | **139.5054%** |
| 标准化输入匹配 | **21.1306%** | **109.8780%** |

原报告的 0.9% 得到复现，但仅存在于错误的目标口径；**“1 个弱阳性实例”应撤回**。这不是发现模型一定不可连，只是当前已展示的低 barrier 证据不成立。

- 原匹配下两个端点完整损失约 **0.01453、0.48012**，并非同等低损失解；以较差端点作分母／门槛会掩盖路径部分位置相对较好端点的大幅恶化。应并列报告绝对 loss、相对 max-endpoint barrier 和相对线性端点插值的 excess。
- B2 的 perm 行列对应已修，当前对下一层列的补偿正确（`:81–90`）。本轮标准化输入上的对齐前后 logit 最大差约 `4.58e-5`，符合浮点求和顺序变化的量级；原始排列 bug 不应继续背锅。
- `:44–62` 是贪心，不是精确 assignment；“优于随机所以 exact”的注释不成立。即使换精确 assignment，也只优化所选层的相关总分，不保证最低 loss barrier，更不能保证跨层最优。
- 更重要的是 `CoordMLP` 尾部 `feat_head→cls` **没有非线性**（`coord_mlp.py:22–28`）。两层可以合并为 `W_eff=W_cls W_feat`、`b_eff=W_cls b_feat+b_cls`。当前匹配只处理两个 ReLU 层，未处理这个线性分解的任意可逆基变换；直接插值两个因子会引入交叉项。高 barrier 可能来自参数坐标，不能归结为 basin 差异。
- 5 对里只有 **2 对跨 era**，另有新种子之间的两对也高 barrier；不能把现象特指为 era 效应。只测九个 α 的直线，也不能排除其他连续低损失曲线。
- `sigma_seed=0.0149` 是 11 个条件均值的跨 seed 标准差，不是插值极差的标准误；`0.0534/0.0149≈3.6` 不是 z 检验或显著性。α 间 miss 集合变化亦未控制。不能仅凭这一个筛出的实例宣称 loss 与位置精度正交。没有完整选择历史，不能断言人为 cherry-pick，但这确实是筛选后的最大极差描述。

## C. 新尝试方案：只列两条正交问题

**全部为 PROPOSED / NOT_RUN。** 信息增益排序：先纠正测量与结论，再 C1，最后 C2。不把修 Spearman、改 Hungarian、扩大 LOO、重做 PIN、重算种子方差称作新机制。不给已失败的监督目标换名重跑，也不重开 Fourier／kink／掠射角特征搜索。

### C1（优先）：同一关系的等价表示是否移动预测根

- **可证伪假说：** 定位不稳定的一部分与端点命名依赖相联系；物理线段和 oracle 不变，仅改变同义的输入排列，模型的命中与根位置仍明显变化。
- **探针：** 对 AB 内交换、CD 内交换、AB↔CD 交换组成的八个排列，同时作用于 x 与 e；固定原始 200 条路径，不能重新选择 aimed 路径。oracle proper-crossing 公式对此不变（`core/relations.py:20–25`），每条路径的 t_star 不变。冻结原有模型，比较同一 parent/path 在八个表示下的完整轨迹、miss 转换、signed root 和额外翻转。先核 oracle 不变；不把八个排列算成八个独立样本。
- **正交点：** 改变的是同一几何对象的表示，不是输入几何难度特征、隐轨迹特征、监督形状、删除训练点或跨随机种子。若真实几何量完全不变而输出变化，原来的几何相关分析根本没有检验这个问题。
- **最小成本：** 0 种子重训×0 epoch；先固定 r04b 三种子，约 `3×200×8×129≈62万` 小 MLP 输入前向，加根精化，CPU 可行。运行时间未实测，不承诺分钟数。
- **判据先行：** 使用 root spread>0.03 或 hit 状态变化定义“不等价”；按 parent 聚类。若至少2/3模型中，超过10%路径不等价且区间下界超过10%，支持该有限现象；若三模型上界均低于10%，否定“至少10%路径有实质命名敏感性”；其余不确定。共同命中根 spread 和全部路径 hit 转换分别报告，不能互相填补。
- **边界：** 观察到敏感性不证明它解释全部误差；也不自动授权对称性增强训练。阈值是未来执行前固定的探索标准，不能根据结果移动。

### C2（次优先）：同一初始函数在不同参数尺度下是否走向不同根位置

- **可证伪假说：** 在函数、数据和目标相同的起点，优化器对参数表示的依赖可能产生实质不同的位置结果；这是优化过程的表示依赖，而非“不同 seed 初始化了不同函数”。
- **设计：** 取 wave 中固定三个 seed 的同一 epoch checkpoint。对固定 ReLU 层施加正尺度 c=1/2、1、2：该层 W/b 乘 c，下一层相应列除 c，理论上保持整个函数。先核对变换前后 train 及 dev logits、根和完整 loss 在数值误差内一致。只从 train_101 clean+既有 flips 更新，目标、batch、线程、dtype 完全相同。
- **优化器控制：** 当前 checkpoint 不含 Adam moments；三臂必须全部重新初始化 optimizer，包括 c=1 对照，明确称“匹配的重启动实验”，不能称原训练无缝继续。选择固定 checkpoint 和固定续训长度，不按 dev 表现挑时刻。
- **正交点：** 不改标签、目标、网络可表示的函数类、训练集成员或初始预测函数；只比较参数尺度与优化规则的共同作用。不同于 seed 方差、训练点钉位和静态路径几何。结果仅支持／反对这个有限敏感性假说，不宣称 Adam 是既有误差的因果来源。
- **最小成本：** 3 seed×3臂×100 epoch = **900 epoch** 的小网络续训；CPU 可行、时间未实测。起点前向检查零训练可先做，任何续训需另行授权。
- **判据先行：** 先要求初始函数差异远小于预设定位容差；比较相同路径上的全路径成功率、积分误差和 miss，同时把终点完整训练 loss 是否可比作为解释条件。若≥2/3 seed 在可比训练损失下，全路径成功率配对差的 parent-cluster 区间完全超出±5pp，支持实质尺度敏感性；若所有 seed 的区间均落在±5pp内，否定该幅度假说；loss 不可比或区间太宽均为不确定，不追 c／epoch。
- **边界：** c=1 控制了重置优化器的共同影响，但不分离所有数值与优化因素；不能把输出差异自动翻译成更好方法。未授权时止于方案。
