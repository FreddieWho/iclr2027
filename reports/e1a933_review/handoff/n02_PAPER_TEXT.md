# N02 论文/附录文字草稿（采样机制 lane）

来源：`reports/e1a933_review/N02_SAMPLING_ACCESS_REPORT.md`、`reports/e1a933_review/N02_INTERPRETATION.md`、`artifacts/e1a933_review/N02_interpretation/`（逐臂指标、逐 parent 配对差、bootstrap CI、预测-结果对照）。
分母：test quartet **178 行 / 85 个 fresh parent**（每 parent ≤4；`small_edit` 分层 **5 行 / 3 parent**）。训练 16 格 × 3 初始化 seed = 48 臂；`seeds=803/805/806` 是三个模型初始化，**不是三个独立任务**。除特别注明外，统计量为 **parent 等权**（先 parent 内平均，再对 85 个 parent 等权），CI 为 4000 次按 parent 聚类 bootstrap。fresh parent 证据：train/dev/test parent 两两最近 L∞ ≥0.1028、1e-6 内匹配 0；全部 train 状态对 test 状态最近 L∞ 0.0707、匹配 0；对 19 个旧 bank 匹配 0（`data_manifest.json`）。

## 总判定

**可以进稿的部分：把 N02 写成"固定观测信息下输入网格/早期采样配置的影响"这一条件性结果 + 一条诚实的机制未决声明（附录或正文限制段）。**

**不可以进稿的部分：任何"我们已经解释了为什么放大图片有用（混叠/信息可访问性）"的机制句。** 冻结的方向性预测只在预训练初始化下命中、随机初始化下未命中且有一个 seed 显著反向，"小编辑更明显"半句在两个初始化下都未被支持，机制判定 UNRESOLVED。

## 可用片段 A（附录 / 正文限制段）：观测信息不变，只改网格

> 在新生成的共同观测合同下（连续胶囊线段渲染，A=native64，B=bilinear(A,224)，两者为同一 64 格像素阵列），用同一 ResNet18 骨干、相同训练配方（20 epoch、Adam 3e-4、batch 32、按 singleton-dev BCE 选 checkpoint、不删任何 seed）在 178 个 quartet（85 个 fresh parent）上评估：B 相对 A 的完整联合正确率 J 提高 ΔJ = +0.340 [+0.258,+0.423]（预训练初始化，3 seed 均值，parent 等权）与 +0.300 [+0.224,+0.380]（随机初始化），即 J 由 0.496/0.581 升到 0.831/0.865（行等权）。该差距分布在"单编辑原子保持"（atomic_joint +0.243/+0.171）与"合取编辑修复"（AB 状态 +0.124/+0.146）两段，而基础静态识别几乎不变（+0.016/+0.012，AUC 已 0.999–1.000）。由于 B 的 conv/linear MACs 是 A 的 12.25 倍（148.0M→1813.6M），我们把该效应表述为"信息不变条件下的网格/算力配置效应"，而不归因为"信息可访问性"。

**可以说**
- "同一像素信息、只放大输入网格，完整联合正确率可差 ~0.30–0.34"——限定本渲染合同、ResNet18、本任务、3 个初始化 seed。
- "差距落在被编辑状态及其合取上，而不是基础静态识别"——AUC 与单状态准确率同步变化，排除"只改阈值"。
- "相同的效应在随机初始化下同样出现"——不是预训练专属。

**不可以说**
- 不能说"这证明了网络没有充分利用已有信息 / 是信息可访问性问题"：MACs 差 12.25×，算力未匹配。
- 不能说"上采样本身就是收益来源"：B 同时使用了大网格与 12.25× 算力，本轮没有做算力匹配对照。
- 不能说"与 D04 的 224 结果拼成同一条因果链"：本 lane 使用新渲染合同（连续胶囊），D04 是整数方形笔刷，两者数字不可相减。

## 可用片段 B（附录）：真实原生高分辨率信息的额外贡献很小

> 在相同合同下，把 B（bilinear 上采样）替换为 C（直接原生 224 渲染）只带来 ΔJ = +0.004 [−0.029,+0.037]（预训练初始化，不可判定）与 +0.040 [+0.011,+0.076]（随机初始化，3/3 seed 同向）；后者的 3.5pp 落在合取状态上（AB 状态 +0.035 [+0.007,+0.074]）。作为对照，把原生 224 低通降采样回 64（D）几乎复现 A（ΔJ = +0.004 [−0.067,+0.073]；随机初始化下 D 反而低 0.094 [−0.146,−0.044]），而 D 相对 C 低 0.340/0.434。

**可以说**
- "网格/算力配置是主效应；真实原生分辨率的额外信息至多解释随机初始化下约 +0.04（≈总尺度效应的 13%）"。
- "低通回 64 与原生 64 无差别"——同一几何内容，只是光栅/降采样方式不同。

**不可以说**
- 不能说"真实高分辨率信息无用"：预训练初始化下本设计的区间跨越 0（不可判定），只能说测不出差异。
- 不能把 +0.04 升格为方法效果（tiny effect 不得升级）。

## 可用片段 C（附录方法段 + 结果段）：冻结方向预测的逐格对照

> 在 GPU 训练 bundle 冻结时（2026-09-24 17:13，`config.json:frozen_prediction`，受 `manifest.json` 哈希校验）写下的结构性预测为："移除 maxpool 会削弱 B 相对 A 的 J 优势，并在最小组成编辑端点位移 ≤2 native64 像素时更明显；即使方向相反也照报，不搜索阈值。" 该预测的符号与分层在任何训练开始前固定（首个训练于 17:32:54 启动，首个臂目录 17:34；写预测数值的 `structural_prediction.json` 是 18:36 由训练后 `protocol.analyze()` 产生，属事后计算）。在 85 个 fresh parent 上逐格对照：预训练初始化下交互量 (B−A)_lowstride − (B−A)_standard 为 −0.133 [−0.213,−0.058]（3/3 seed 同向，去掉任一 seed 后仍在 −0.115 到 −0.149 之间），命中；随机初始化下为 +0.020 [−0.042,+0.081]，其中一个 seed 显著反向（+0.110 [+0.029,+0.190]），未命中。预测的第二半（小编辑更明显）在两个初始化下都未被支持（小编辑分层交互 −0.056 与 +0.056，方向与预测相反），且该分层只有 5 quartet / 3 parent，被判定为不可判定。机制判定因此为 UNRESOLVED（预先写下的规则是"若不消除就不要继续把混叠当解释"）。

**可以说**
- "一个在训练前冻结符号、分层与报告规则的结构预测，在 85 个全新 parent 上对预训练初始化命中、对随机初始化未命中。"
- "命中幅度为 B−A 差距的 39%（−0.133 / +0.340）。"
- "小编辑分层只有 5 quartet / 3 parent，无辨识力，不能用于任何外推。"

**不可以说**
- 不能说"预测命中，所以机制是早期下采样/混叠"——随机初始化下不成立，且低stride 同时改变池化/感受野并把 MACs 提到 3.80×。
- 不能说"事前固定了数值"：事前只有符号、分层阈值与报告规则，数值事后才知道。
- 不能引用第二半预测为"成立"；它是点估计反向 + 不可判定。
- 不能说"低stride 让 native64 变好就等于混叠是原因"：预训练初始化下 A 臂自身 +0.211 [+0.148,+0.279]，B 臂只 +0.078 [+0.043,+0.116]，"差距变小"主要来自 A 变好。

## 可用片段 D（附录）：static-only 对照定位效应

> 在只有静态状态监督（从不喂入编辑样本，但每 epoch 曝光数与 flip 臂相同）的对照臂上，B−A 的 J 差距为 +0.391（预训练）与 +0.365（随机），与 flip 臂的 +0.340/+0.300 同级，交互 (B−A)_static − (B−A)_flip = +0.050 [−0.044,+0.141] / +0.065 [−0.048,+0.176]（均不可判定）。同时，flip 监督自身的增益在 A 上更大（+0.226/+0.348）而非 B（+0.175/+0.282）。

**可以说**
- "尺度效应不需要变化监督来显现"，因此它不是"修复学习"或"阈值"的产物。
- "尺度效应使合取判定更接近其条件上界：CCM 由 0.728→0.888（预训练）/0.773→0.933（随机）"。

**不可以说**
- 不能说"尺度效应专门改善完整 repair"：在 static 臂中基础识别那一层也出现差距（+0.098/+0.094），只是 flip 臂已把该层做到天花板。

## NOT_FOR_PAPER 清单

1. **任何"我们解释了放大图片为何有用（混叠/早期下采样/信息可访问性）"的机制句** —— 冻结预测只在预训练初始化命中，随机初始化未命中且一个 seed 反向；机制 UNRESOLVED。
2. **"放大输入网格是免费收益"** —— B 的 MACs 是 A 的 12.25 倍，且低stride 是 3.80 倍；没有算力匹配对照。
3. **"小编辑对尺度更敏感"** —— 唯一相关分层 5 quartet / 3 parent，点估计反方向，不可判定。
4. **"重新训练后上采样不再有用/仍然有用（作为一般规律）"** —— 本矩阵只有 ResNet18、单渲染合同、单任务几何；`docs/e1a933_review/03_NEW_HIGH_VALUE_ROUTES.md` 明确禁止声称首次发现 CNN 对输入尺度敏感。
5. **把本 lane 的 48 臂数字与 D04 旧 224 结果相减得到的任何"因果差值"** —— 渲染合同不同（连续胶囊 vs 整数方形笔刷），旧 checkpoint 数字必须单列。
6. **"3 个 seed 是三次独立确认"** —— 它们是三个模型初始化；bootstrap 只覆盖 parent 抽样不确定性。
7. **旧塌缩 seed 的"已修复"表述** —— 新矩阵 48 臂无塌缩，但这是新渲染合同 + 新 bank + 新训练配方的结果；旧诊断里 seed803/train224_random 的 J=0 塌缩仍然保留在历史子节，不能声称被修好。
