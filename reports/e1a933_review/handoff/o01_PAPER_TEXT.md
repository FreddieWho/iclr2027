**来源**：`experiments/e1a933_review/o01_continuation.py`；产物 `artifacts/e1a933_review/data_o01_continuation/`；
完整报告 `reports/e1a933_review/O01_DATA_OPTIMIZATION_REPORT.md`。
**评价分母**：新 parent 池的 1229 个 quartet / 250 个 eligible parent（从 512 个抽取的 evaluation parent 中，
其余未产生合法 E）；所有配对区间都按 parent 聚类做 2000 次 bootstrap（seed 924），三个 seed 只作描述性汇总。
**执行合同**：648 次真实训练；同一 (size,arch,seed) 的 warm 臂共用同一 clean 起点参数哈希与同一 batch 列表
（209/209 断言通过，`CHECK_REPORT.json`）；选择只用 static/single 开发 BCE，评价池 J 从不参与选择。

## 可直接进正文的句子（每条一句，带分母与不确定性）

1. **表示决定变化监督的转化效率，且不是“raw 没调好”造成的**：在同一个未见 parent 池（1229 quartet / 250 parent）上，
   用同一 clean 起点、同样 300 步全批训练，成对距离输入的联合正确率 J 比原始坐标高
   ΔJ = +0.434…+0.561（N 与 4N × 3 seed × 3 学习率共 18 个等配方配对，parent 聚类 95% CI 全部不含 0）。
2. **该优势在换优化器族后仍然存在**：把候选扩到 SGD momentum（.01/.003）与 Adam 低学习率长跑（5e-4 × 600 步）
   并按开发集 BCE 选择后，距离 − 原始坐标在 f100 仍为 +0.475…+0.574（warm 与 scratch 两个起点、N/4N × 3 seed，CI 全部不含 0）。
3. **两个分布不重叠**：在全部 648 个配置中，原始坐标在 f100 的最高 J 为 0.168（N）/ 0.345（4N），
   距离输入在 f100 的最低 J 为 0.562（N）/ 0.737（4N）（描述性范围，未用于任何选择）。
4. **标签效率**：在已挖完全池的条件下，只用 25% 的保留变化标签（N 383 条 / 4N 1,597 条）的距离模型
   就超过用 100% 标签（N 1,534 / 4N 6,390）的原始坐标模型，ΔJ = +0.378…+0.542（等配方配对，CI 不含 0）；
   距离输入从 0% 到 25% 的涨幅已占总涨幅的 88–96%。
5. **起点不帮忙**：从 clean（只用基础数据、300 步）权重续训 flip 训练，并不优于一开始就把 flip 放进训练；
   同一学习率下 warm − scratch 在距离输入的 f100 为 −0.081…−0.024（N）、−0.056…−0.033（4N），部分 CI 不含 0，
   在 f0 上差 ≈ 0（−0.001…+0.020，CI 全部含 0）。
6. **正交互有条件**：J 尺度交互项 I = (距离_d − 距离_0) − (原始_d − 原始_0) 在 24 个 cell×剂量×起点组合中
   22 个的 CI 不含 0（N 上 +0.228…+0.356；4N 上 +0.022…+0.223）；例外是 4N/scratch/f100 的两个 seed
   （+0.022，CI [−0.057,+0.104] 与 [−0.032,+0.123]）。
7. **保护类损失买的是“不忘”不是“更对”**：PCT 式软保护与 hard-label replay 在同一剂量、同起点、
   同一步数下与普通续训的 J 差 |ΔJ| ≤ 0.053（多数 CI 含 0），但在未见 parent 上把
   “起点正确原子在训练后变错”的比例降低 4–12 个百分点（raw 上 3/3 seed CI<0）；
   真实 preserve+flip 平衡臂降幅最大（如 N/raw/f100：0.241→0.150；4N/six/f100：0.042→0.021），
   且只用了一半的变化标签。
8. **成本口径**：25% 子集是在挖完全池之后抽取的，挖掘阶段 oracle 查询对所有剂量完全相同
   （N 147,514 次 / 4N 587,320 次候选查询，分别保留 1,534 / 6,390 条变化标签），
   因此该结果支持的是**监督侧（保留标签）的数据效率**，不是 oracle 查询效率。

---

## 可以说

- 在上述任务、输入与训练预算下，成对距离表示把同样的变化监督更有效地转化为“联合正确”，
  并且这个优势在充分搜索的原始坐标基线（3 档 Adam + SGD momentum 两档 + Adam 低 LR 长跑、两个起点）之上仍然成立。
- 变化标签的收益在 25% 保留量处已接近饱和（88–96%），因此**在已挖完全池的条件下**继续增加保留标签的边际收益很小。
- 从 clean 权重出发再补变化监督，不优于联合训练；这否定了“只要从干净模型续训就能救回”的旧解释。
- 保护/replay/平衡类损失不提升联合正确率，但降低对起点正确原子的破坏；平衡臂用一半变化标签达到相近 J。
- 25% 与 100% 是同一个池上的不同保留量，不是两个独立测试集；N 与 4N 是同一规模因素的两个水平。

## 不可以说

- 不能说“省下 75% oracle 查询/标注成本”：挖掘成本与剂量无关，只有训练侧保留标签减少。
- 不能说“raw 已经被优化到容量上限所以差距是表示的性质”：raw 臂普遍欠拟合（warm/f100 有 13/72 臂训练误差 >5%），
  且未做参数匹配（raw in_dim=8 vs sixdist in_dim=6）；能说的是在已覆盖的优化器族与起点下差距仍然巨大。
- 不能说“保护损失导致 J 提升/下降”或“PCT 救回塌缩”：J 上没有稳定效应；
  剂量 0 的保护臂是纯蒸馏正则，其开发 BCE 仍停在 clean-only 水平，不能当作有 flip 训练的证据。
- 不能说“所有剂量/规模格都呈正交互”：4N/scratch/f100 的两个 seed CI 含 0。
- 不能说本结果来自长期预训练的表示：clean 起点只是 300 步 static-only 模型。
- 不能把 1229 quartet / 250 parent 池称作“未见首读确认集”：它是本轮新 parent 池，但同批实验已多次使用。
- 不能说 preserve 池代表自然保持事件：它是模型无关、模长受对应 flip 范数限制的人工同标签扰动。
