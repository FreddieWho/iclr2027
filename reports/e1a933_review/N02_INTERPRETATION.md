## 1. 问题 (a)：B vs A（同一像素信息、只放大网格）

**我的预设怀疑**：这可能是 (i) 决策阈值移动，(ii) 单纯算力，(iii) 只在"被编辑状态"上补票而不是真的更懂关系，(iv) 预训练先验被放大。逐条查：

| 怀疑 | 检验 | 结果 |
|---|---|---|
| (i) 只是阈值 | 每状态阈值无关 AUC；单状态测试准确率 | AUC_state3 0.755→0.954（pretrained）/0.735→0.938（random）；flip 单片准确率 0.950→1.000 / 0.959→1.000 → **排除"只改阈值"** |
| (ii) 只是算力 | MACs（`structure_matrix.json`） | 148.0M→1813.6M = **12.25×** → **不能排除**，只能写成"信息不变、算力/网格变化" |
| (iii) 只补票 | 分量分解 + 110→111 计数 | atomic_joint +0.243/+0.171，AB_state3 +0.124/+0.146，P_state0 +0.016/+0.012；A 臂 110 基线 36/32/31 中 29/21/23 被修成 111 → 优势**同时**落在原子保持与合取修复，且基础识别本就在天花板（排除"基础识别"假说） |
| (iv) 预训练放大 | random 臂 | random 下 ΔJ=+0.300[+0.224,+0.380]，与 pretrained 同量级 → **不是**预训练专属效应 |

判断：**"固定观测信息、改变输入网格可造成 ~0.3 的完整联合正确率差距"成立**（两初始化、6/6 seed 同向、LOO 稳健：pretrained 0.321/0.339/0.361，random 0.324/0.284/0.292）。**"这证明了信息可访问性而非算力"不成立**，因为算力差 12.25× 没有被匹配。

## 2. 问题 (b)：C vs B（真实原生高分辨率信息）

**怀疑**：C−B 若为 +0.04 这种小量，会不会只是噪声/种子波动？

- pretrained：+0.004 [−0.029,+0.037]，per-seed +0.032/−0.049/+0.028，**符号不稳定**（LOO：−0.010/+0.030/−0.008）→ 判定**不可判定**，不能说"原生分辨率无用"，只能说本设计在 pretrained 下测不出差异。
- random：+0.040 [+0.011,+0.076]，per-seed +0.065/+0.017/+0.039，符号稳定（LOO 0.028/0.052/0.041）→ 小的真实效应；其中 AB_state3 +0.035 [+0.007,+0.074]，atomic_joint +0.014 [−0.004,+0.031]（不可判定）。
- 参照量级：C−A ≈ B−A（+0.344/+0.340 vs +0.340/+0.300），所以原生信息解释不了主体效应，至多解释 random 下约 +0.04（≈13%）。
- 低通对照：D（native224 area 降采样回 64）≈ A（+0.004 [−0.067,+0.073] pretrained；random 下 D 反而 −0.094），D−C ≈ −(C−A) → 与"信息量"关系小、与网格关系大。

判断：**"已有信息的网格/算力配置是主效应，真实原生分辨率的额外信息只在 random 初始化下有小的、可测的额外贡献"**。

## 3. 问题 (c)：lowstride 是否消掉 B 相对 A 的优势（冻结预测）

**我会被推翻的方式**（先写下来）：如果交互量的符号由单个 seed 决定、或者随机初始化下同样为负、或者 lowstride 提升的是 B 臂而不是 A 臂，那么"低stride 削弱了 B 的优势"就不能给我一个采样机制的解释。

数据：

| init | 交互 | per-seed | LOO（去掉任一 seed） | 符号稳定 |
|---|---|---|---|---|
| pretrained | **−0.133** [−0.213,−0.058] | −0.169 / −0.128 / −0.102 | −0.115 / −0.135 / −0.149 | 是 |
| random | **+0.020** [−0.042,+0.081] | +0.110 / −0.072 / +0.022 | −0.025 / +0.066 / +0.019 | 否 |

进一步的"我试图反驳自己的第一版解释"：

1. 我最初想写"移除 maxpool 消除 aliasing，所以 B 的优势是混叠"。**反驳成功**：在 random 初始化下交互为正（seed803 +0.110 [+0.029,+0.190]，显著反向），而且 pretrained 下 lowstride 抬高的主要是 **A 臂自身**（+0.211 [+0.148,+0.279]），B 臂只 +0.078 [+0.043,+0.116]。也就是说"B−A 变小"更自然的读法是"低stride 把 native64 这一路修好了"，而不是"B 的机制被移除"。因此**不给 aliasing 归因**。
2. 我想用"低stride 同时是 3.8× 算力"来救场，但同一逻辑会摧毁 (a) 的解释：A 臂在 random 下 lowstride 只 +0.037（不可判定），2/3 seed 同向但不足噪声门槛，说明"更多算力"本身不自动带来 J。→ 结论只能是**初始化 × 早期网格/池化配置的条件性交互**，不是一个通用机制。
3. 按 `N02_GPU_EXECUTION_PLAN.md` 写死的规则（"若不消除，不要继续把 aliasing 当解释，报告未解决"），此处判定 **UNRESOLVED**。这不是"预测失败"可以一笔带过：pretrained 下确实命中且 LOO 稳健（3/3 负、2/3 CI 排除 0），random 下未命中。

预测第二半"小编辑（≤2px）更明显"：

- pretrained：small_edit −0.056 vs other_edit −0.131 → **点估计方向与预测相反**。
- random：small_edit +0.056 vs other_edit +0.021 → 方向与"负"相反（虽然是正的小量）。
- 分母：small_edit 只有 **5 行 / 3 parent**，CI 宽到无意义（[−0.333,+0.333] / [−0.167,+0.333]）。→ 记 **不可判定 + 点估计不支持**，绝不允许被引用为"尺度效应集中在细小编辑"。

## 4. 问题 (d)：尺度效应作用在哪一层（static-only 对照）

**我的预设怀疑**：B 的优势也许只是"更会用 flip 监督"，即尺度改变的是"修复学习"，而不是"看见"。

反驳它的证据：

| 量（cross-seed，parent 等权） | pretrained flip | pretrained static | random flip | random static |
|---|---|---|---|---|
| B−A，J | +0.340 | +0.391 | +0.300 | +0.365 |
| B−A，atomic_joint | +0.243 | +0.235 | +0.171 | +0.096 |
| B−A，P_state0 | +0.016 | +0.098 | +0.012 | +0.094 |

- static-only 臂（没有见过任何编辑样本）里 B−A 同样大甚至更大 ⇒ **尺度效应不依赖 flip 监督**；交互 `(B−A)_static − (B−A)_flip` = +0.050 [−0.044,+0.141] / +0.065 [−0.048,+0.176]，不可判定。
- flip 监督本身的收益（flip−static）在 A 上略大（+0.226/+0.348）于 B（+0.175/+0.282），说明"监督红利"并未被尺度放大；这也是对"尺度效应=修复学习"的第二个反证。
- 位置分解：flip 臂中 gap 集中在被编辑状态（state1/2）与其合取（atomic_joint、AB_state3），基础静态识别 P_state0 差异≈0（AUC 0.999–1.000 已天花板）；static 臂中 P_state0 也出现 +0.098/+0.094（交互 +0.082 [+0.039,+0.129]），因为 flip 臂把这些基础判断先做到天花板了。
- 阈值论再排除一次：AUC、CCM、110→111 修复计数同步变化（见专报 4(d)）。

判断：**尺度效应作用于"被编辑状态 + 其合取"这一层，不作用于基础静态识别，也不是阈值移动；它不需要 flip 监督来显现。**

## 5. 我仍然没能排除的替代解释（写成清单，避免读者以为已解决）

1. **算力/容量路径**：B 12.25×、lowstride 3.80× MACs。要真正分离，需要 MACs 匹配的对照（例如加宽 A 的骨干），本轮没有做，也不在本 lane 授权内。
2. **特征图尺寸 vs 感受野 vs 数值精度**：lowstride 同时改变池化、感受野、动态范围和中间激活尺度；三者在本设计里不可分。
3. **预训练权重与输入尺度的适配**：ImageNet 权重在 224 上"更像"训练时的统计；pretrained 与 random 交互符号不同正是这一混杂的体现，不能倒过来说"预训练先验已被排除"。
4. **任务/几何特定性**：只测了红/蓝胶囊线段的关系 quartet、单骨干 ResNet18、单一渲染合同；跨任务/跨骨干未测。
5. **细小编辑层欠采样**：5 行/3 parent，任何关于小编辑的层级断言在这里都没有辨识力。
