# X01 round1 一页纸：显式关系交互 vs 平面 MLP（等参、同数据、同配方）

源：`artifacts/next6_ef0f7a3/x01/result.json`。预算 6401 参（raw h=64，6849 参，
±7% 内）；同 flipmine 数据（1534 flips＋train_101）；同 300ep 全批量 Adam；
评 U01 固定未见四元组 n=547。

## 真实结果（emergent miss）
- raw：0.373 / 0.388 / 0.455（均 0.405）
- rel_bilinear：0.448 / 0.442 / 0.369（均 0.420）
- rel_concat：0.419 / 0.410 / 0.450（均 0.426）
- 三臂互有胜负，乘法算子 vs concat-only 无系统差（0.420 vs 0.426）

## 混杂（已识别，未洗白）
关系网静态 err 0.20–0.30、原子 0.38–0.49，全面差于 raw（0.12–0.14 / 0.47–0.56）：
固定 300ep 下结构网没学好基本功，组合比较被"欠优化"污染。
替代解释二选一：（a）同样本下结构网学得慢，比较不公平；（b）交互假设真错。
round1 数据杀不死 (b)，也证实不了 (a)。

## x01b（1200ep，三臂更新量仍相同）：混杂未洗白，park
- raw：0.373 / 0.369 / 0.455（300ep 时 0.373/0.388/0.455——raw 早已平台）
- rel_bilinear：0.444 / 0.435 / 0.371；rel_concat：0.397 / 0.435 / 0.437
- 关系网静态仍 0.21–0.31（raw 0.12–0.15）：4 倍更新没追上基本功，
  “欠优化”解释失血；乘法 vs concat 均值 0.417 vs 0.423，无系统差。
- 结论：在此任务/配方下，显式交互归纳偏置无证据；raw MLP 的 flipmine
  基线（emergent ~0.40）仍是最好成绩。park，不再调参（无机制理由的新设计）。
