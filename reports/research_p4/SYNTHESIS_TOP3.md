# Research 综合：三条最有希望的路线（2026-09-05）

来源：三条并行 researcher 轨道（`reports/research_p4/` A 谱近似 / B 塌缩机制 / C 不确定性）。
综合原则：机制证据强度 × 与现有设置的相容性；两个轨道独立收敛的结论优先。

## 跨轨道收敛（高置信）

1. **n=20 时精确谱分解在各方面占优**（A＋C 独立得出）：Chebyshev 存在的
   唯一理由是回避大图对角化；20×20 `eigh` 按 batch 在 GPU 上是微秒级，
   比 R=5×6 多项式路径更便宜且零误差。Chebyshev 应当删除，不是调参。
2. **6 等宽频带过 resolving 离散谱**（A＋C）：20 个特征值高度非均匀，
   多个频带在多数 snapshot 上是空的，输出的是邻带泄漏而非带内含量。
   应改为 2–3 个密度均衡频带（或按经验特征值密度划界）。
3. **塌缩是 complete collapse 类，有命名、有因果验证的解**（B）：
   SimSiam（stop-gradient 非对称）、VICReg（最终嵌入上方差＋协方差）、
   GradNorm/PCGrad（梯度冲突手术）。我们的失败签名（margin 恒 0.2、
   对称零净梯度）与文献中的稳定不动点一致。
4. **Shannon 数 K≈0.3–0.8（C 的定量杀手）**：中/高频带＋小支持（2–5 节点）
   的"局域化频带干预"本质上不存在良定自由度（μ 即上限）。这不是工程
   问题，是基本界——**无论 v3 成败都必须进论文 Limitations**，且
   Slepian-probe 设计（带纯度保证的频带×区域探针）目前无发表先例，
   本身可写成方法贡献。

## Top-3 路线（按尝试顺序）

### 路线 1：精确谱基础（A1＋C1/C2）——先修"看不见的"误差
- 精确 `eigh` 谱投影代替 Chebyshev-5；频带减至 2–3 个密度均衡带；
- 干预采样改 Slepian 向量（B·S·B 集中算子主特征向量），逐 trial 报告 μ；
- Slepian-matched nulls（同 S 邻带、同带互补区）作对照格。
- 判定：频带能量相关性 exact-vs-旧近似；μ 分布；路由诊断的带纯度。
- 代价：小（采样器＋滤波器替换，不动训练主循环）。

### 路线 2：最终嵌入防护（B3＋B1）——堵住塌缩不动点
- VICReg 式方差 hinge＋within-mode 协方差去相关移到**最终 64 维
  mode embedding**（实际进入三元组的那一层），floor 按归一化后尺度校准；
- 路由不变/恢复分支加 stop-gradient 非对称（扰动分支预测固定的干净目标）；
- mode embedding L2 归一化＋semi-hard mining＋active-triplet 占比守卫
  （命中 0 即判塌缩中止）；每 eval 记录嵌入奇异谱（Jing 诊断）。
- 判定：pair 从 epoch 1 起学习（loss < margin）、奇异谱无零堆积、
  干预 ρ 有限。
- 代价：中（改 route_batch＋损失＋训练循环守卫）。

### 路线 3：梯度尺度平衡（B2）——工程层保险
- 初始化时测共享主干处各损失梯度范数，路由权重 rescale 至 ≤ context 范数；
- GradNorm（α≈1.5）每 ~100 步调权重；context＋triplet 先 warm-start
  至 pair 超 chance，路由权重 0→封顶 ramp；PCGrad 作备用。
- 判定：训练全程路由/任务梯度范数比有界；不再出现单种子主干级联破坏。
- 代价：中（GradNorm 权重控制器）。

## 对 v3 存活率的预读

v3（全频带可恢复＋归一化读出）仍保留两个文献指出的塌缩通道：
中间层方差下限可被 MLP 旁路、路由梯度对称无 stop-grad。
因此 v3 若存活，功劳归"可恢复性惩罚塌缩"；若仍塌缩，直接按
路线 1→2→3 顺序尝试（每条以锁附录预注册，dev-only，单变量优先）。
