# A10 — Cross-sport transfer (basketball): literature & data feasibility

## Summary
Basketball was correctly parked: the only public NBA *tracking* data is a frozen 2015–16 SportVU archive, current Second Spectrum data is proprietary, and BigDataBall is box-score/play-by-play (not trajectories). Multi-sport architectures exist (CVPR 2019; baller2vec 2021; Sports-Traj; AdaSports-Traj 2025), but none establishes soccer→basketball representation transfer as routine — so a cross-sport claim must meet a frozen-encoder replication bar, and unfreezing requires a named dataset plus a preregistered transfer test.

## Statement 1 — Dataset options (access conditions)
- **(a) SportVU 2015–16 frozen archive: FEASIBLE, gated.** Last season of publicly served raw optical tracking (25 Hz x,y for 10 players + ball, possession-level files); later seasons moved behind proprietary feeds. Community mirrors exist (e.g., HuggingFace `dcayton/nba_tracking_data_15_16`; "94 GB" archive documented on r/datasets; `ismayc/tracking-study` notes raw tracking is "only a frozen 2015-16 archive"). Access = scrape/mirror reuse, no license grant; publication use requires provenance note + cite league source. Peer-reviewed reuse precedent: Jiao et al. 2025 used 632 games of 2015–16 SportVU (venue: journal article, ScienceDirect 2025). **Evidence grade: medium-high** (primary-source status confirmed by NBA PR on SportVU availability + multiple reuse papers; exact redistribution rights remain gray). Researcher inference: sufficient for feasibility work, not for a "current NBA" claim.
- **(b) Second Spectrum (2017→present, incl. "Dragon"/mesh): NOT FEASIBLE without partnership.** Official NBA tracking provider since 2017 (Second Spectrum), acquired by Genius Sports 2021; 2023 NBA–Genius expansion confirms data is integrated into proprietary products, with no public bulk release. Access = commercial/team/league agreement only. **Evidence grade: high** (NBA Communications PR 2023; Genius Sports newsroom 2021). Inference: do not budget on obtaining this.
- **(c) BigDataBall: NOT tracking — EXCLUDE for trajectory transfer.** Sells game-by-game Excel datasets (team/player stats, odds, play-by-play) for NBA/WNBA/NCAAB etc., free sample + paid full files; no x,y trajectories. A citing paper (PMC 9164576, 2022) describes it as shot coordinates/stats source. **Evidence grade: high** (bigdataball.com/datasets + help pages). Inference: usable for event-level baselines only, never as a tracking-replication substrate.
- Soccer-side anchor (context): SoccerTrack-v2 = 10 university matches / ~934 min, panoramic 4K, GSR/BAS/MOT + toolkit, gated HuggingFace release; preprint Scott et al., arXiv:2508.01802 (2025, cs.CV). **Grade: high.**

## Statement 2 — What transfer would prove (and what exists)
- Existing multi-sport work proves *shared architectures run* on both sports, not that *soccer-learned representations transfer*: Yeh et al., "Diverse Generation for Multi-Agent Sports Games," **CVPR 2019** (basketball + soccer generative model); Alcorn, baller2vec **arXiv 2021 (2102.03291)** + baller2vec++ (multi-entity Transformer, NBA trajectory/ball forecasting, code public); Fu et al., "Sports-Traj" **OpenReview preprint (~2024–25)** unified generation model; ECML-PKDD **2025 preprint ads_1458** trains/evaluates one imputation method separately on soccer (Metrica), basketball (SportVU first 100 matches), and American football; Xu et al., AdaSports-Traj **arXiv:2509.16095 (2025)** explicitly tackles role- and domain-aware adaptation across sports. **Grade: medium** for "architectures span sports"; **low** for "soccer→basketball zero-shot transfer works" (no replicated cross-sport frozen-encoder result found).
- A cross-sport replication therefore must, minimally: (i) freeze the soccer-trained encoder (no basketball fine-tune for the zero-shot variant); (ii) fix a coordinate-normalization + agent-count adapter (23 soccer vs 11 basketball agents) *before* seeing basketball test data; (iii) report the same metric family as the soccer claim (e.g., imputation error / probe AUC) on SportVU 2015–16 with a preregistered null (permuted-roles / shuffled-agent baseline); (iv) disclose any basketball-tuned variant as a separate, weaker claim. Passing (i)–(iv) would prove sport-agnostic multi-agent structure; failing while same-sport controls pass would bound the claim to soccer. This bar is researcher inference from the adaptation literature (AdaSports-Traj; AdapTraj domain-generalization framework, arXiv 2023), not a quoted standard.

## Statement 3 — Unfreezing conditions (keep parked until ALL hold)
1. Named basketball substrate committed (default: SportVU 2015–16 mirror + file manifest) with license/provenance note cleared for publication; 2. Adapter + metric + null preregistered in writing before first basketball evaluation; 3. A same-sport control (IDSSE-dev → SoccerTrack-v2 external) already passing, so cross-sport is an extension, not a rescue. Until then, basketball stays parked — no download, no pilot. (Normative recommendation; inference.)

## Contradictions
None on core facts. Minor: venues/dates for Sports-Traj (OpenReview, exact conference year unclear) and AdaSports-Traj (arXiv Sept 2025 vs IEEE Nov 2025 proceeding entry) — treat both as 2025 preprints/proceedings, not established archival results. BigDataBall is sometimes misdescribed as "tracking-adjacent"; vendor pages confirm it is not trajectory data.

## Missing evidence
