# Research: S6 — Calligraphy isomorphism as outlook seed

## Summary
Calligraphy is a legitimate isomorphism probe: multi-stroke spatial representations where global pose/style entangles with internal structure, mirroring the players-vs-formation problem. A credible outlook needs only (a) true vector stroke graphs from Make Me a Hanzi, (b) skeleton-derived pseudo-graphs with stated caveats, and (c) a minimal, explicitly non-claiming demo. All three cost far less than a new experiment thread.

## Findings
1. **Claim:** Make Me a Hanzi provides true vector stroke data: `graphics.txt` holds per-stroke SVG paths for 9000+ characters, plus `dictionary.txt` and animated SVGs. **Sources:** repo README (github.com/skishore/makemeahanzi); hanzi-writer docs (hanziwriter.org). **Support:** direct evidence (repo file layout, license notes). **Confidence:** high. *Researcher inference:* strokes parse directly into polylines → nodes (endpoints/junctions) + edges (stroke segments) with hours of CPU code; no training needed for a qualitative figure.
2. **Claim:** Skeleton→graph ("characters as graphs") is an established representation with known failure modes (noise sensitivity, stroke discontinuity, complex structures). **Sources:** Gan et al., Pattern Recognition 137:109317, 2023 (skeleton graphs + Pyramid Graph Transformer; code ganji15/PyGT-HCCR). **Support:** direct evidence for method; interpretation that failure modes transfer to calligraphy. **Confidence:** high (method exists) / medium (transfer). *Implication:* any skeleton pseudo-graph demo must disclose thinning artifacts — this honesty is what makes the outlook credible.
3. **Claim:** Structure-vs-style disentanglement is the live question in font/calligraphy generation, and stroke-graph priors help. **Sources:** Wang et al., DeepVecFont-v2, CVPR 2023 (dual image+sequence modalities, transformers for complex Chinese structures); SCI-Font, ECCV 2024 proceedings ch. (skeleton+contour guided calligraphy generation); SSR-GNN, arXiv:2204.13153, 2022 (strokes-as-nodes, inter-stroke-as-edges for sketches). **Support:** direct evidence (paper abstracts/code). **Confidence:** medium-high. *Researcher inference:* citing this line lets the paper frame calligraphy as "where our disentanglement claim would break or generalize" rather than a random second domain.
4. **Claim:** A minimal isomorphism demo costs ~days, not a new project. **Support:** researcher inference (not source-stated). **Confidence:** low-medium. Breakdown: parse 100–500 characters from graphics.txt → stroke graphs (0.5–1 person-day, CPU); render side-by-side pose-vs-structure entanglement figure (0.5–1 day); optional frozen-encoder transfer of one metric to skeleton graphs (1–2 person-weeks, single GPU, 2–4 GPU-days). No new data collection; all assets are open (Arphic Public License lineage — check compliance before redistributing derivatives).

## Outlook formulations (pick ≤2; at most 3 offered)
**O1 — One-paragraph qualitative probe (recommended; cheapest, safest).** Scope: one figure + one paragraph noting strokes↔players, character pose↔team shape entanglement; explicitly "illustration, not evaluation." Cost: <1 person-week, CPU only, zero GPU. Why it strengthens: shows the abstraction is domain-agnostic without adding an unreviewed claim; reviewers read it as vision, not incompleteness. Evidence grade: demo-level.
**O2 — Skeleton-graph transfer pilot (one extra result).** Scope: build pseudo-graphs from binarized+thinned glyphs for N≈200 characters; report one frozen-metric number (e.g., retrieval/consistency) with artifact caveats; state thinning sensitivity per Gan et al. 2023. Cost: 1–2 person-weeks, ≤4 GPU-days. Why it strengthens: converts analogy into a falsifiable stress test while quarantining noise in an appendix/footnote. Evidence grade: pilot-level, not SOTA.
**O3 — Vector-stroke generative stress test (programmatic, for rebuttal-proofing).** Scope: name — don't run — a follow-up: conditional generation over stroke graphs (cf. DeepVecFont-v2 CVPR23; SCI-Font ECCV24) testing whether the method separates global pose from internal structure. Cost if pursued later: ~1 person-month. Why it strengthens *as text now*: signals a concrete research program ("the natural next falsifier is…") instead of vague "future work will explore more domains." Write it in 2–3 sentences max.

## How to write it without looking unfinished
- Frame as *boundary condition*, not missing experiment: "If the claim is about entanglement per se, it should survive where entities are strokes…" (researcher writing advice, no source).
- Use hedge verbs once ("would predict," "illustrates") and forbid a third claim sentence; end the paragraph on the current paper's contribution, not the seed.
- Quarantine method detail (thinning algorithm, polyline sampling) to appendix/supplement or omit under O1; detail invites review of work you did not do.
- Never promise O2/O3 results ("we will show"); promise only the question ("the test would be…").

## Contradictions
None found on the core facts. Note: skeleton-based papers report gains from skeleton guidance (SCI-Font; SGCE-Font) while recognition work acknowledges skeleton fragility — these coexist (guidance helps on clean data; artifacts dominate on noisy/handwritten data), so cite both sides.
