# Research: A7 — Test-time adaptation using the routing head

## Summary
Test-time adaptation (TTA) updates a model on unlabeled test inputs via entropy minimization (Tent), augmentation-consistency (MEMO), or an auxiliary self-supervised loss (TTT). It helps under moderate covariate shift with sufficient well-calibrated samples, and hurts under small batches, mixed/label-shifted streams, or long online runs where entropy minimization collapses to trivial confident solutions. For OUR system the safe use is: treat the Slepian-based band-recoverability routing head as a gate and auxiliary objective — adapt only high-recoverability bands, filter the rest, and reset episodically.

## Findings

1. **Claim:** Tent (fully TTA by entropy minimization; adapt only norm-layer affine params) improves corruption robustness but degrades with small batches and continual streams. **Sources:** Wang et al., ICLR 2021 (Spotlight); Niu et al., ICLR 2023 (SAR). **Support:** direct evidence. **Confidence:** high.
   - Tent protocol: minimize prediction entropy on each test batch, updating only BatchNorm affine parameters; no source data, no labels. Gains reported on CIFAR-10-C / ImageNet-C.
   - Failure documented by SAR: mixed shifts + small batches + online class imbalance cause instability/collapse; researcher inference: our spectral-band setting (per-snapshot single sample, variable missing-band pattern) is exactly the small-batch regime where vanilla Tent is risky.

2. **Claim:** MEMO (marginal entropy over augmentations of a single test point, episodic reset) works per-sample and avoids long-horizon drift; cost is K forward/backward passes per sample. **Sources:** Zhang et al., NeurIPS 2022 (arXiv 2021). **Support:** direct evidence. **Confidence:** high.
   - Protocol: create ~16–64 augmentations of one test input, minimize entropy of the averaged (marginal) prediction, adapt all or subset of params, then reset to source weights before the next sample. Researcher inference: episodic reset is the simplest collapse guard we can copy; per-sample cost is the main drawback.

3. **Claim:** TTT uses a joint supervised + self-supervised (e.g., rotation) training, then fine-tunes the shared encoder on the auxiliary loss alone at test time; TTT++ shows it fails when the auxiliary task is uncorrelated with the main task or the feature alignment is poor, and fixes it with feature alignment + stronger SSL. **Sources:** Sun et al., ICML 2020 (TTT); Liu et al., NeurIPS 2021 (TTT++). **Support:** direct evidence. **Confidence:** high.
   - Relevance (interpretation): our routing head is a natural auxiliary head — band-recoverability prediction is correlated with the main reconstruction/classification task by construction (Slepian concentration tells which bands are inferable), so it satisfies TTT++'s "auxiliary must correlate" condition better than generic rotation. Confidence medium — correlation is argued from Slepian theory, not yet empirically verified in our data.

4. **Claim:** When TTA helps vs hurts is now fairly characterized: helps on benign covariate/corruption shift with large balanced batches and short horizons; hurts or goes inactive on label shift, open-world/noisy streams, tiny batches, and long continual runs without reset/regularization. Guards with evidence: sample filtering by entropy threshold (EATA, ICML 2022), sharpness-aware updates + recovery trigger on collapsing loss (SAR, ICLR 2023), stochastic weight restore / mean-teacher (CoTTA, CVPR 2022). **Sources:** Niu et al., ICML 2022 (EATA); Niu et al., ICLR 2023 (SAR); Wang et al., CVPR 2022 (CoTTA). **Support:** direct evidence for guards; application to our setting is researcher inference. **Confidence:** medium-high.

## Three concrete TTA proposals using OUR routing head

**P1 — Gated Tent on routed bands only (online, batched).**
- Protocol: freeze full backbone; allow updates only to norm-affine params plus per-band gain of bands the routing head scores recoverable (e.g., p_recover > 0.6). Minimize prediction entropy on current batch restricted to routed-band outputs; bands scored unrecoverable are masked from the loss and downstream fusion.
- Guard: EATA-style filter — skip samples with entropy above threshold (unreliable) and below near-zero (already collapsed); hard cap of 1 step/batch, lr ≤ 0.25× train lr; track running entropy; if batch-mean entropy drops >50% in N steps or routing-head calibration (ECE) worsens, restore last checkpoint (SAR-style recovery).
- Expected gain (inference, medium-low confidence): +2–8% robust accuracy / −5–15% error on moderate missing-band/corruption shift vs no-TTA; ~zero gain and explicit abstention on fully-unrecoverable inputs. Grade: evidence medium (Tent+EATA transfer), mechanism fit high.

**P2 — Episodic MEMO-TTA weighted by routing confidence (single-sample).**
- Protocol: per test snapshot, generate K augmentations (band dropout / noise consistent with Slepian forward model, not generic crops); compute marginal prediction averaged over K; one gradient step minimizing marginal entropy weighted by routing confidence w̄ (mean p_recover over used bands); predict; then reset weights to source (fully episodic, no cross-sample carryover).
- Guard: collapse impossible across samples by construction (reset); within-sample guard by K≥16 and weight w̄ — if w̄ < τ_abstain, take zero steps and output "unrecoverable" instead of adapting.
- Expected gain (inference, medium confidence): best single-sample robustness; cost ~K× inference latency. Grade: evidence medium-high (MEMO single-sample result transfers directly to our per-snapshot regime).

**P3 — TTT with routing head as the auxiliary self-supervised objective.**
- Protocol (requires joint training now): train encoder + main head + routing head jointly (main loss + λ_routing × recoverability loss on synthetically masked bands). At test time, freeze both heads, fine-tune encoder only for 1–3 steps on routing loss alone (predict Slepian recoverability / reconstruct held-in band coefficients from observed bands), then predict with adapted encoder.
- Guard: TTT++ lessons — (a) verify auxiliary/main correlation offline (routing loss improvement must predict main-task improvement on validation shifts, else disable P3); (b) adapt encoder only, never the heads; (c) episodic or Fisher-regularized updates toward source weights; (d) stop if routing loss does not decrease within 3 steps.
- Expected gain (inference, low-medium confidence): largest gain on novel missing-band patterns if correlation holds; largest risk if it does not — hence ship P1/P2 first, P3 behind a flag. Grade: evidence medium for mechanism, low for magnitude until we run the correlation check.

## Contradictions
- Tent-family papers report steady gains on CIFAR-C/ImageNet-C; SAR/CoTTA/pitfalls literature reports degradation under continual, small-batch, or mixed shifts with the same methods. Resolution in literature: both true under different stream conditions — this is why guards resists are load-bearing, not optional. None found on MEMO episodic safety or TTT auxiliary-correlation requirement.

## Missing evidence
- No direct evidence on Slepian-band routing as a TTA gate (novel to our system); the P1–P3 gain numbers are extrapolations from vision-corruption benchmarks, not spectral-recovery data.
- Optimal τ thresholds, K, lr, and λ_routing for our data unverified — needs a small TTA calibration split with synthetic band-missing shifts.
- Latency budget for P2 (K augmentations × backward pass) vs deployment constraints unknown.
