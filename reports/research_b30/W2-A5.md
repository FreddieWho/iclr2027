# Research: A5 — Structured equivariant architectures with built-in centroid/mode separation

## Summary
Our repair (raw-coordinate "context" channel + centered-coordinate "intrinsic" channel with asymmetric updates) can be built structurally — not learned — in three ways: (1) EGNN-style invariant/equivariant split, (2) centroid-frame averaging with an unconstrained backbone, (3) learned canonicalization (center-then-predict). All three have primary sources; (1) and (2) give exact E(2) guarantees by construction.

## Findings

**1. Claim: EGNN explicitly separates an invariant feature channel (h) from an equivariant coordinate channel (x); only relative vectors drive x-updates, so freezing the raw-context branch while updating the centered branch is equivariance-preserving by construction. Sources:** Satorras et al., E(n) Equivariant Graph Neural Networks (ICML 2021). **Support:** direct evidence — messages m_ij from invariant inputs (h, ||x_i−x_j||²); x-update is Σ(x_i−x_j)·φ_x(m_ij) with scalar invariant weights; h-update uses only invariants. **Confidence:** high.
*Researcher inference:* This is the closest structural match to OUR separation. Design D1: **Frozen-context EGNN.** Branch C (context) = raw coords, used only inside invariant edge scalars, never coordinate-updated. Branch I (intrinsic) = centered coords, the only tensor passed through φ_x coordinate updates. Asymmetric allocation = all x-update parameters/gradients on I; C contributes only distance/angle scalars. Translation equivariance follows because C enters only via differences/norms.

**2. Claim: Frame Averaging (FA) makes ANY backbone E(2)-equivariant/invariant by averaging over a small equivariant frame — canonically a centroid + PCAorientation frame — cleanly splitting "frame origin" (context/centroid) from "frame-relative input" (intrinsic). Sources:** Puny et al., Frame Averaging for Invariant and Equivariant Network Design (ICLR 2022 Oral); Duval et al., FAENet (ICML 2023). **Support:** direct evidence — FA theory (exact equivariance via group-frame average); FAENet uses stochastic frame averaging (SFA) with a centroid-based frame and an otherwise unconstrained GNN, competitive on materials benchmarks. **Confidence:** high for exactness claim; medium for SFA approximation (stochastic subset trades exactness for speed — stated in Duval et al.).
*Researcher inference:* Design D2: **Centroid-frame-averaged backbone.** Compute centroid c (context carrier, handled by a tiny invariant head or passed through untouched); feed x−c in PCA frame to existing repair backbone (intrinsic path gets ~all capacity); average outputs over the 4–8 frame elements (full FA for proof; SFA at train time per FAENet). Centroid/mode separation is then in the frame definition, not in training.

**3. Claim: Learned canonicalization achieves equivariance by an equivariant canonicalizer predicting a group element (translation+rotation), canonicalizing the input, running a free predictor, and mapping back; canonicalization subsumes frames and exposes where capacity goes. Sources:** Kaba et al., Equivariance with Learned Canonicalization Functions (ICML 2023); Mondal et al., Equivariance with Learned Canonical Mappings (NeurIPS 2022); Ma et al., A Canonicalization Perspective on Invariant and Equivariant Learning (NeurIPS 2024). **Support:** direct evidence for method; interpretation for capacity claim (canonicalizer is small/equivariant, predictor is large/free — Kaba et al. design). **Confidence:** medium-high (method high; E(2)-image canonicalizer stability medium — discontinuity at symmetric inputs noted in literature).
*Researcher inference:* Design D3: **Center-canonicalized predictor.** Tiny equivariant head predicts c (or c+R); canonicalize x→x−c (optionally derotate); large backbone sees only canonical view (intrinsic, asymmetric updates by design); add back c at output if equivariant output needed. Simplest E(2) instance is fixed canonicalizer c=mean (reduces to centering + invariant net) — zero learned-frame risk; learned rotation is the optional upgrade.

## Contradictions
None found on core guarantees. Trade-off dispute recorded: FA/FAENet authors present SFA as efficient with small variance; canonicalization literature (Ma et al. 2024) shows frames/canonical forms can be discontinuous for symmetric inputs — so learned frames trade smoothness for flexibility vs. fixed centroid frame (D2-fixed) or EGNN relative-vector form (D1), which avoid the issue.

## Missing evidence
No direct benchmark of "frozen raw-context + updated centered-intrinsic" asymmetry under these three wrappers on our data — allocation ratios must be set by us. E(2)-steerable CNN alternative (Weiler & Cesa, NeurIPS 2019) covers grid images, not needed for point-coordinate repair; listed only as rejected.
