# P3 artifact index

`P3_FINAL_EXECUTION_MANIFEST.json` records the frozen P2 surface, current
configuration, run-time configuration snapshots, source hashes and task
roots. Each task root retains its own receipt/checksum files and limitations.

- `support_geometry_v1/`: T0, T1 retrospective and T3 layer/block outputs.
- `support_geometry_prospective_v1/`: T2 response-blind intervention and validation.
- `selected_causal_switch_v1/`: T4/T5 single switch, objective task, robustness and localization outputs.

P2 roots are read-only and are not duplicated here.
