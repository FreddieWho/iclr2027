# 独立评审意见：Action-Mode Spectrum vs. Compression-Path Memory

我按文档要求的框架给出诚实评估，同时会指出文档本身可能低估或未充分强调的风险点。

## 一个先要说明的元问题

文档引用的近邻文献包括"ICLR 2026""ICLR 2027 Reviewer Guide""arXiv 2026-05/07/08"等——这些日期都晚于任何可验证的现实时间点，说明**这份材料本身是一次模拟/压力测试练习**，其"近邻工作"是被设定出来用于测试两个方案的抗冲击能力，而不是真实存在的、已核实的文献。这一点必须明确：

- 这不影响两个方案*内在设计质量*的评估；
- 但意味着文档中"已经被 XX 工作抢先"的结论目前是**假设性风险**，不是已核实事实。真正投稿前，两个方向都需要做一次**真实、穷尽的当期查重**，而不能依赖本文档里列出的（可能是虚构占位的）近邻工作列表来判断安全边界。

这一点文档自己也部分承认（3.8.3 提到"这一区分需要进一步系统查重才能确定"），但没有把这个不确定性同等地应用到风险评级上——两个方案的"最大 prior-art 风险"栏目其实都应该加一个更大的误差棒。

## 方案 A：Action-Mode Spectrum

### 我认为文档没有讲透的核心问题：Jacobian 结果的"重言式"风险被低估了

文档在 2.8.4 已经诚实提到 `‖Jδ‖` 本身就是局部响应的一阶近似，但随后并没有真正解决这个问题，只是把它列为"需要额外证明"的待办事项。我想再强调一下这个风险的严重程度：

0.8466 这个相关系数，本质上是在说"泰勒展开的线性项能预测泰勒展开本身在小扰动下的行为"——这在数学上几乎是**必然**的，尤其是在扰动幅度可控的实验设置下。这不是一个可以被"额外证明"稀释掉的小问题，而是**当前最亮眼的数字本身缺乏意外性（surprise）**。ICLR reviewer 大概率会在这里直接发问："如果 full local geometry 优于 diagonal/off-diagonal 分解，这是不是只是说明你用了更完整的一阶信息，而不是发现了新机制？"

这意味着方案 A 当前"最强证据"（2.6.1 的表格）在没有下游任务验证的情况下，**论文价值被严重打折**。文档自己也承认这一点（"only证明改变表示，不能证明修复任务"），但把它列为"待完成"而不是"核心风险"，我认为低估了严重性——这不是一个"还没来得及做"的问题，而是"如果做不出来，整个 headline 结果的解释力就会崩塌"的问题。

### 其他实质性风险

- **Heldout 污染**：这是一个方法学诚信问题，不只是"证据不够强"。如果 candidate search 阶段确实在排序流程中接触过 heldout 指标，即使排序公式未直接使用，一个仔细的 reviewer 也可能质疑整个 pipeline 的数据泄露风险。这一条比文档语气显示的更接近"fatal"而非"边界"问题。
- **任务定义的语义冲突**（2.6.4）目前仍未解决，意味着当前所有下游 task 数字都不能直接使用，需要重新设计评价协议后重跑。
- **受众规模**：文档没有讨论的一点是，足球战术阵型 + 图书法这两个测试床对 ICLR 主流审稿人（多数来自表示学习/视觉/NLP 核心方向）而言相对陌生，"这个问题重要吗"的说服成本比在更主流数据集（如 ImageNet 类、标准图数据集）上做同类工作更高。这会拉低 significance 打分，即使技术严谨。

### 我的评分

| 维度 | 分数 | 说明 |
|---|---|---|
| Scientific interest | 7/10 | 概念新颖（operator×support×task），但受众窄 |
| Novelty after adjustment | 5/10 | 与 partial equivariance 系列区分度依赖细节执行 |
| Evidence tractability | 6/10 | pipeline已存在，但需要重做任务定义+清洁heldout |
| ICLR fit | 6/10 | 若无downstream gain，只能算强diagnosis paper |
| **当前状态下预计中稿概率** | **约 30–40%**（若完整执行最低充分证据清单，可到 45% 左右） | 主要卡点是downstream task gain能否做出来 |

**Fatal concern**：(1) 无法证明几何差异有任何任务后果；(2) heldout 污染若未妥善处理，可能被审稿人直接质疑严谨性。

## 方案 B：Compression-Path Memory

### 优点被文档准确抓住

这个方案的最大优势确实是**方法论干净**：固定 final budget、正交化 depth/schedule、query-blind compression、retention vs accessibility 拆分——这套实验设计本身的严谨度，即便最终效应量很小，也足以构成一篇合格的 benchmark/empirical-law 论文的骨架。这是文档判断最准确的地方。

我认为文档里**最值钱的部分不是"path effect 是否存在"这个 headline，而是 retention/accessibility 的解耦**（3.2）。这个拆分本身就有独立价值：即使 path effect 很弱，如果能证明现有 benchmark 长期把"证据还在但读不出来"和"证据真的丢了"混为一谈，这本身就是一个有意义的方法论贡献，不完全依赖 headline 假设成立。文档在 3.7 的创新点 B3 里提到了这一点，但没有把它提升到"即使主假设落空，这仍是独立可发表贡献"的高度——我认为应该这样定位，这会显著降低这个方向的下行风险。

### 核心风险：零 pilot + 极度拥挤的赛道

这是文档诚实地反复强调的问题，我完全同意：

- 三篇高度相关的工作（Rate-Distortion View、Compaction Cliff、Decision-centric）在几个月内密集出现，说明这是一个**正在被多个团队同时攻克的窗口期极短的问题**。即使现在的区分点（严格固定 final budget vs 固定每轮比例）成立，也很可能在实际投稿前被另一篇 concurrent work 提前覆盖——这是纯粹的赛道拥挤风险，跟方案本身质量无关。
- 更麻烦的是：如果 pilot 结果显示"控制 final budget 后，depth 的独立效应很小"，那么整个方向没有像方案 A 那样的"诊断论文"保底形态——文档 4.10 也承认这一点。这是一个**高方差、无安全垫**的赌注。

### 我的评分

| 维度 | 分数 | 说明 |
|---|---|---|
| Scientific interest | 8/10 | 话题热度高，问题直觉性强 |
| Novelty after adjustment | 4–5/10 | 赛道拥挤，区分点较窄 |
| Evidence tractability | 7/10 | 不需要训练模型，可快速跑pilot验证/证伪 |
| ICLR fit | 7/10 | benchmark/empirical-law paper有先例可循 |
| **当前状态下预计中稿概率（无条件）** | **约 20–30%** | 若pilot证实稳健效应，可跳到45–55% |

**Fatal concern**：(1) 固定budget后path效应太小或不稳定；(2) 与近期工作区分度不够，被判定为增量控制变量实验。

## 横向比较与我的实际建议

如果不严格考虑时间成本，纯粹看**风险调整后的期望价值**：

1. **方案 A 的问题更深，但当前最强证据的说服力有一个结构性硬伤**（近似重言式），这个硬伤不能靠"多做点实验"完全消除，只能靠**重新定位 claim**（不强调相关系数本身，而强调"能不能预测独立数据上的失败模式并造成任务后果"）来绕开。这是一个论文叙事策略问题，比方案 B 的问题更难通过"多跑几组实验"解决。

2. **方案 B 的问题更表层但更致命**：核心假设完全未验证，且赛道拥挤程度是文档里两个方向中最高的。但好消息是，这个方向**验证成本低、反馈周期短**——花一到两周做 pilot（固定 budget、2-3 种 depth、1-2 个 compressor/evaluator）就能大致判断 path effect 是否存在、量级如何。这意味着方案 B 的**不确定性可以被快速消解**，而方案 A 的核心不确定性（downstream task gain 能否做出来、跨域能否成立）需要更长的实验周期才能见分晓。

3. 如果一定要给一个"目前更接近可投稿证据闭环"的判断（这是文档 0.1 明确要求单独回答的问题）：**方案 A 更接近**，因为它已经有可以收缩成 diagnosis paper 的下限；但如果要求"独立评估两个想法本身的天花板与性价比"，**方案 B 的核心设计（尤其 retention/accessibility 拆分）在假设成立的前提下，重要性和可传播性略高于方案 A**，因为它触及一个更大、更热的用户群体（agent memory）关心的问题，且不依赖新方法就能成立。

### 如果只能选一条路线

我会建议：**先用一周左右的低成本 pilot 检验方案 B 的核心假设（fixed-budget path effect 是否存在、量级多大）**，因为这是全文档中"验证成本最低、决策价值最高"的单一实验。如果 pilot 阳性且效应量不小，方案 B 性价比更高（更少工程量、更大受众、方法非必需）；如果 pilot 阴性或效应很弱，立即转向方案 A，但**必须先解决 heldout 污染和 Jacobian 结果的叙事重构问题**，否则即使补完下游任务实验，仍可能在 rebuttal 阶段被审稿人抓住"这个相关系数是不是显然的"这一点不放。

两个方案目前都不具备"稳赢"的证据基础，都需要至少一轮关键实验的阳性结果才能真正谈中稿概率——这一点文档本身的克制态度是对的，我不会在此基础上给出比它更乐观的结论。
