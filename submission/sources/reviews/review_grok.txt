## 我怎么打分

ICLR 审稿人真正卡的是四件事：问题是不是清楚、跟最近邻差在哪、证据是否撑住主 claim、社区拿走什么新知识。你们这份材料写得很克制，这很好；但材料里已经标出来的缺口，恰恰就是审稿时会被打的点。我不会把“已经做了很多实验”算成科学优势，也不会把“还没做”算成概念劣势。比较的是：**扣掉最近邻之后还剩多少新东西，以及那点新东西有没有可证伪的最低证据。**

## 方案 A：Action-Mode Spectrum

**问题本身有质量，但比最初设想弱了一档。** “同一个算子作用在谁身上、服务什么任务，语义可以不同”——这是一个真问题，而且比 “global invariance vs local equivariance” 更值得做。真正的风险是：你们最初更强的故事（统一的中频组织盲区）**没有立住**。当前能站得住的版本变成了：图频率不够，support 上的局部几何更能预测响应，并且这套几何可被架构开关改写。这仍然可以成文，但冲击力明显下降。审稿人看到的不会是“我们发现了一个被忽略的结构盲区”，而更可能是“在足球 tracking 图上，Jacobian 比频谱更能解释局部响应”。

**最大的新颖性风险不是被抢发，而是被归类。** PooDLe、partial equivariance、probabilistic symmetry breaking、soft equivariance 这棵文献树很成熟。如果最后读起来仍是“全局该不变、局部该等变”，贡献会被压成特殊情形。Jacobian 相关 0.85 更危险——\(\|J\delta\|\) 本来就是局部响应的一阶近似，这不能当标题级发现。你们材料里对这一点的自省是对的。A 要活，必须证明三件事同时成立：

1. 等能量、等 support size、近频率下，**真实 coalition ≠ 随机 coalition**；
2. 这个差异在**独立赛事/独立结构**上重复；
3. 改变这套几何，会产生**语义正确的任务后果**，而不是只改了探针指标。

缺第 3 点，论文形态会从“新表示方法”滑成“网络解剖”。ICLR 收过机制分析，但收的是干净、可泛化、让人改看法的机制；不是“我们在一个领域数据上把 Jacobian 拆开了”。

**当前证据的结构是头重脚轻。** 诊断、JVP、support 干预、layer anatomy、pooling 开关，这些是真东西，所以 A 有下限。但最大 blocker 也已经暴露：改 pooling 能改几何，**还没有稳定的 downstream gain**；现有 phase classification 还把绝对位置和阵型结构拧在同一个标签里。AMR 完全未启动，书法跨域也未完成。足球 tracking 作为主测试床本身就有领域偏置——没有第二域，很容易被写成 sports representation 而不是一般的 structured representation。

**成功形态和失败形态不对称。** 最强版本（AMR + 任务收益 + 跨域）是机制+方法论文，上限不低。更可能的完成态是：独立数据上复现几何规律，coalition 对照成立，任务收益没有或很弱，于是改投 diagnosis/anatomy。这个降级版**可以投稿，但不稳**。ICLR 对“分析得很细但没证明这很重要”的论文通常是撕裂的：soundness 给到 6，significance 给到 4，然后 borderline。

**我对 A 的概率判断：**

- 只把现有诊断包装投稿：大约 **0–5%**。主 claim 撑不住，任务定义有内部冲突。
- 完成最低充分证据（独立确认 + coalition 对照 + 至少一个任务相关后果，AMR 不做）：大约 **20–30%**。这是 A 最现实的可投形态。
- 完整成功（AMR 真的带来正确的 task/robustness 收益，再加一个跨域）：大约 **35–48%**。够海报，口头发言仍难。
- 把“任务收益做不出来、AMR 做不出来”这些已知风险折进去后的期望：大约 **18–25%**。

A 的文献风险是静态的：不太会明天突然被抢走，但审稿人会问“这不就是局部几何 / 部分等变吗”。

## 方案 B：Compression-Path Memory

**问题更干净，也更烫，因此窗口更窄。** “最终 token 预算相同，记忆质量是否仍依赖压缩路径”——这是一句审稿人 30 秒能懂的话。方法不是必须项，配对反事实好做，社区相关性明显高于足球图表示。LongMemEval、BEAM 已经证明：高质量分析/基准可以进 ICLR。这些都是真优势。

**但 2026 年 7–8 月的近邻几乎把主创新的第一层吃掉了。** 这一点比材料里写的还严重一点。

Colaco 等人的 rate-distortion 工作已经把 KV / prompt / agent memory 放进统一框架，做了 repeated irreversible summarization，提出了 COMPACT-Bench，并在相近平均预算下看到累积误差。Compaction Cliff 更直接：固定每轮压缩，多轮后安全约束保留从一轮约 53% 掉到五轮约 10%，而且已经中了 CIKM 2026。到 ICLR 2027 审稿时，审稿人几乎不可能没见过这两篇。

所以 B **不能再靠**下面这些句子吃饭：

- 反复压缩会丢信息；
- 不同类型信息丢失速度不同；
- 应该做 type-aware compaction。

剩下的缝是真实的，但薄：严格锁死 final budget，把 depth / schedule 正交化；one-shot vs multi-stage 的反事实；retention 和 accessibility 拆开；看有没有滞后、相变、排序反转。这不是“新问题”，是“更干净的析因控制”。析因控制可以中稿，前提是结果必须非平凡。如果严格配平预算之后，路径效应很小，或者完全能被“每轮删掉的信息”解释，论文会瞬间变成增量基准。

还有一个被低估的点：**信息论事先就不站在“惊人发现”这一边。** 数据处理不等式和有损压缩的复合，已经定性预言路径依赖。B 的贡献必须是经验上的超额部分：效应量、错误类型、可达性与保留的分离、某种反直觉的 schedule 效应。没有这些，审稿人会写：“interesting control, but expected.”

**当前完成度是零。** 核心假设未验证。这对期望概率的杀伤比 A 大，因为 A 至少已经知道诊断规律在一个数据上存在；B 连“固定预算后路径效应是否存在”都不知道。无方法兜底时，规律一旦不新，没有第二条命。

**我对 B 的概率判断：**

- 固定预算后路径效应弱，或只能写成“压得越多忘得越多”：大约 **3–10%**。
- 找到稳定、跨模型、配平预算后仍在的路径效应，再加 retention/accessibility 分解：大约 **22–38%**。这是 B 的主活路，形态类似 empirical-law / analysis paper。
- 再出现至少一个反直觉结果（access-loss 交叉、某类信息的相变、one-shot 与 repeated 的排序反转）：大约 **35–50%**。这时传播性会强于 A。
- 把“效应可能平凡 / 可能被近邻覆盖 / 还没有 pilot”折进去后的期望：大约 **10–18%**。

B 是高方差题。做成了，引用和话题性都好过 A；做不成，没有 diagnosis 可以收缩。

## 面对面：哪个更像 ICLR 论文

| 维度 | A Action-Mode | B Compression-Path Memory | 更占优的一方 |
|---|---|---|---|
| 问题清晰度 | 中高，概念负担重 | 高，一句话能讲清 | B |
| 扣掉近邻后的新知识 | 中，取决于 coalition 是否真是新坐标 | 中低，取决于固定预算后是否还有非平凡路径效应 | 略偏 A |
| 证据成熟度 | 已有机制证据，缺任务闭环 | 无 pilot | A 明显 |
| 方法是否必须 | 强版本必须有 AMR | 不必 | B |
| 失败后的下限 | 可降级为 anatomy 论文 | 几乎没有降级形态 | A |
| 被抢/撞车 | 低，文献稳 | 高且还在动 | A |
| 审稿人兴趣/传播 | 中，领域偏置风险 | 高 | B |
| 科学风险 | 诊断转不成任务价值 | 路径效应可能平凡 | 不同性质 |
| 最可能可投形态的中稿率 | 20–30% | 22–38%（若效应存在） | 条件依赖 |
| 计入失败可能后的期望 | 18–25% | 10–18% | A |

一句话：**A 是期望值更高、方差更小的题；B 是上限更高、更可能直接死的题。** 两者即便做成，也更像海报而不是 oral。

## 更硬的判断

如果问的是“哪一个现在更接近 ICLR 主会”，答案是 **A，而且不是很接近**。它差的是独立确认、任务语义拆分、以及至少一处因果任务后果。这些是已知、可执行的缺口。AMR 我不建议当成投稿必要条件——它更像加分项；把 AMR 当主贡献，是在一个尚未证明“改几何有用”的地方再叠一个未验证方法，审稿时会被看成故事写得比证据大。

如果问的是“哪一个更值得为 ICLR 押注”，我仍然选 **A 的收缩版（机制诊断，而不是 AMR 方法论文）**，原因很具体：

1. A 已经有非零的机制事实；B 的主假设还是假设。
2. B 的剩余新颖性是实验设计上的精细化，不是问题坐标上的迁移。精细化可以中，但必须出惊人结果；惊人结果没有先验保证。
3. Compaction Cliff 已经中 CIKM。ICLR 审 LLM memory 的人会直接拿它当标尺。B 必须证明自己不是“把每轮 50% 换成固定终点预算的更干净复现”。
4. A 的领域偏置是真问题，但可以用篮球低成本重复来部分补，不必等书法。书法如果做薄，反而有害。

B 只在一个条件下更值得押：你们愿意先用很小的成本做 **budget-matched path effect 的pilot**。如果配平最终预算、配平 compressor、控制 iterative rewrite 之后，multi-stage 对 direct 仍有稳定效应量，B 会立刻超过 A——因为问题更热、论文更好写、方法不是瓶颈。如果 pilot 显示效应很小，B 应该停，不要靠“再加 information type、再加 hysteresis”去挽救一个可能不存在的主效应。

## 两个方案各自最容易被拒的理由

A 最可能收到的拒稿是：

> 局部 Jacobian 预测局部响应并不令人惊讶；support-conditioned geometry 没有在独立数据上转化为任务层面的新知识；与 partial equivariance 的区分更多是表述而非实验。

B 最可能收到的拒稿是：

> 反复有损压缩累积误差已被 rate-distortion 与 Compaction Cliff 讨论；本文在固定预算下的路径效应要么偏小，要么仍可被普通信息删除解释，贡献偏增量。

这两句我都可以想象出现在真实评审里。它们不是吹毛求疵，而是对你们材料里已经承认的弱点的直译。

## 如果必须选一条冲 ICLR

选 **A，但按机制论文而不是方法论文来做**。最低要交的卷子是：新比赛上复现、真实 coalition 对随机 coalition、context task 和 structure task 拆开、架构开关对应一个可解释的任务方向变化。做完这四项，中稿率大概在四分之一上下。AMR 和书法都是锦上添花，不要让它们定义论文是否成立。

B 不要在没有 pilot 的情况下当成主投。它现在不是研究方案的完成态，是一个还没过第一道证伪门的假设。过了那一扇门，它会比 A 更好投；过不去，它比 A 更没有退路。

两者都不要按“强成功版本”的故事去估概率。按你们自己写的最低充分证据，A 大约五分之一到四分之一，B 大约十分之一到六分之一。这已经算实话；再往上调，是在把尚未发生的实验结果提前记成分。
