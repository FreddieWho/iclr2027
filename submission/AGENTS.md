# 工作区规则

总控负责数据/结果合同与最终决策。建议最多 4 个 worker：D 数据与评分；E 运行器与实验；A 统计/证据审计；L 文献与 Action-Mode 备忘核对。worker 不独立启动重复大规模 API 作业。

一份任务一个 owner，一个共享 ledger，一个只追加的结果目录。配置和代码可在探索期改；确认期修改导致分析目标变化时标记 exploratory，不能继续称独立确认。没有要求外部预注册、签字审批或每步人工批准。

不得改变 `sources/` 原文。备忘与源文件冲突时，报告原文，另列独立判断。来源优先级：实测 artifacts > 已确认运行配置/源代码 > 原始论文/数据说明 > 附件审计意见 > 本包设想。不存在真实 artifact 时必须说“待测”。

先保证静态同历史因果比较，不把流式更新、RAG、隐式平台记忆、原生 /compact、KV 缓存压缩混为一个条件。任何自动平台隐藏压缩都必须关掉或将该路径标为不可解释的系统黑盒。
