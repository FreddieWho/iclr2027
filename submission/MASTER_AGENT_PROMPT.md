# 总控 Agent 启动 Prompt

你正在执行 ICLR Memory Pilot，不是在写论文，也不是要证明用户的想法一定正确。完整阅读本文件、README、docs/01–06 和 docs/09；Action-Mode 只阅读 docs/08，不执行其施工建议。

## 唯一主交付
完成 bounded pilot，输出 `reports/PILOT_REPORT.md`、`reports/decision.json`、全部逐样本/逐压缩步骤证据及可复跑命令。最终只允许 GO 或 NO_GO，并使用 docs/05 的理由码。不得用“值得继续看看”代替决定，不得把 API/数据阻塞写成科学阴性。

## 科学核心
比较同一 H 的 direct 与 staged memory。主估计量是最终预算下的 paired utility difference；depth 与 schedule 不等于独立纯因果因子，比较条件须说明总调用、输出量和可访问原文。正式压缩时看不到未来问题、答案、证据标签和其他路径记忆。

核心信息类型：原子事实、时序更新/来源、跨节点关系、带例外/撤销的约束。测量原始上下文、一次压缩、两种二阶段路径、三阶段路径、等终点重复改写、延迟收紧对照。参考 configs/pilot.json；不得一开始运行所有模型×所有路径×所有数据的全组合。

## 执行顺序
1. 在独立目录或分支工作。运行离线测试。发现本地已有授权模型 endpoint、native tokenizer、上下文与最大输出限制、价格和现有可用经费；不读取/展示 key 值。完成 `reports/PREFLIGHT.md`。没有 API 授权仍应完成本地准备，但不得擅自开通付费服务。
2. 并行启动数据/runner 联调和近邻查重。查重使用 docs/07 已核验入口，重点是是否已有相同 H、相同最终预算的 direct/staged、相同深度 schedule 及 rewrite 控制；不以标题相似直接判重复，不拖到“穷尽文献”才允许小额合法 pilot。
3. 先做 6–8 个不进入统计的数据联调，只修长度控制、解析和评分故障。随后做 32 个独立可控历史的探索，模型 C1/R1，一种压缩 prompt，两种预算。优先缓存记忆，重复使用于 reader，而不是重复压缩。
4. 按 docs/02 与 docs/05 选择至多两个确认主对比，记录 `configs/confirmation_selection.json`。它不是外部预注册；选完后不要再用确认集改 prompt、阈值或候选。做 96 个新历史确认，必要时一次扩到总计 192；不是为追 p 值逐个追加。
5. 至少补一个泛化方向：第二 compressor family、第二 reader family或自然 LongMemEval 子集。优先把 C1 记忆交 R2 读，以区分存储和读出；主线若声称模型普遍性，必须再有 C2。自然数据默认 32 个探索/确认之外的完整历史，不能按已知答案挑保留片段。
6. 做 length、rewrite、oracle/no-memory 校准及 24–48 个错误/成功配对的证据审计。每个失败类别必须有实际例子及原始证据。公开原文恢复只作诊断，不混入主排名。必要扩展至多两项、一次补测；边界见 docs/02。
7. 运行统计与决策器，审核自动报告的出处和分母。生成 GO/NO_GO；同时附“仍未回答什么”。若 GO，仅提出下一阶段最小建议，不自动训练新架构或启动正式 benchmark 扩展。
8. 交付 Action-Mode 备忘的位置即可；不得顺手去做 A 的实验、重写结果或推翻用户原来的方法创新要求。

## 授权与资源
现有、明确授权资源优先。包中美元限额必须由已有授权配置或用户给定；没有明确信息不得把本包建议当成消费授权。调用数/token 预算为工程上限，不是预计费用。GPU 只有形成真实硬阻塞且解释现有 API/CPU 不足后才申请。遇到 key/费用等硬阻塞只一次说明所需内容，其余不阻塞的本地工作继续完成。

## 禁止行为
不能把“单调下降”直接判 trivial；不能要求为了好看必须相变。不能把不显著说成等价。不能把 8 个同历史问题当 8 个独立历史。不能只数 max_tokens 而不数实际 memory 长度。不能为了配平事后给某臂单独修长度/补原文。不能把 regeneration/reaccess 与不可逆压缩混在一起。不能用技术失败填错答案。不能把六份 LLM 审计当六个独立实证研究，也不能平均其主观中稿概率。

## 结束标准
本包的全部必需产物存在、测试通过、报告中每个数字可追到 row/请求/hash，且 decision.json 是本次真实结果。mock 只能叫 smoke test。若资源耗尽或有效样本不足，明确 NO_GO_EVIDENCE，不伪装成效应为零。不得以“继续探索”无限延长任务。
