## 1. 共同认可的问题，不等于共同认可的解决方案

六份评审都担心当前headline落在“Jacobian可以预测局部响应”，并要求将几何分析连到语义正确的任务后果。它们也普遍提醒support/coalition与partial equivariance的区分、独立确认和体育/书法测试床的泛化说服力。但**是否必须做完整AMR、是否必须换主数据集、diagnosis是否真的有稳固兜底，并无共识**。

各评审的接收概率跨度很大，未提供可校准证据；不平均、不把它们当六票统计投票。六份报告都基于同一份材料，其结论存在共同输入相关性。

## 3. 三个必须保留的争议，不静默调和

### 3.1 AMR：原用户目标与审计建议并不相同

Grok主张按机制论文推进，完整AMR不是必要；Qwen认为一条task-level causal link可以足够；Opus要求把AMR提升为必需，并改/补标准测试床 [Grok L94–123; Qwen L26–32; Opus L32]。

**独立建议：** 不在未澄清任务语义时堆AMR；也不把这当永久放弃方法创新的依据。恢复顺序应是任务语义→受控后果→简洁方法→扩展。原项目用户曾要求至少一个实质方法改进，此约束仍在；本包只是备忘，不授权将A悄悄降为纯诊断。

### 3.2 足球/书法：泛化风险真实，但换知名数据集不是自动解药

Opus建议替换主测试床或增加标准benchmark；Grok允许篮球做低成本重复并将书法降优先级；Gemini提到独立比赛或合成3D骨骼作为检验 [Opus L16/32; Grok L99–103/123; Gemini L52–55]。

**独立建议：** 以可观察结构、客观任务和同一机制为选择依据。若只是为了“主流”加入标签语义并不匹配的数据集，反而扩大工程与解释负担。可优先选择一个能精确指定support且有客观输出的标准/受控结构任务；这里不指定新必下载数据，也不新增本轮施工。

### 3.3 Heldout：需要修复证据等级，不等于可推定研究不诚信

Sonnet把heldout暴露强调到诚信风险 [Sonnet L28]。已有进度材料说候选搜索展示了heldout，但排序公式没有直接使用。因此当前可支持的结论是“独立确认属性已受损”，不是“已证明训练泄漏、造假或所有结果无效”。

**独立建议：** 标记暴露、保留全部结果和历史、新数据确认、验证程序没有提前访问。不要删除历史，也不要把全管线都宣判无效。是否存在额外泄漏须另有代码证据。本包没有重审最新仓库。

## 4. 两项数学/机制表述的独立校正

以下不是审计原文结论，而是本包的分析。

### 4.1 Jacobian的准确含义

对足够光滑f，f(X+δ)−f(X)=J_f(X)δ+O(||δ||²)。因而 1/2||Jδ||² 是平方表示距离的领先二次项，而不是“平方距离本身的一阶项”。有限扰动、分段线性网络跨区域等情况可能不由同一个局部线性映射充分近似；因此ρ≈0.85不是逻辑恒真，也确有经验信息。但单凭该数字，创新仍然不足。

应重点检验：block结构解释了哪个原有频率坐标解释不了的失败；它能否预测独立样本/有限幅度上的方向；改结构会不会改变语义正确的任务行为。不能把full信息优于diagonal信息单独卖成惊讶结论。

### 4.2 support-restricted操作未必不是group action

若固定support S，定义 T_S(g)在i∈S时施加g、其他节点保持不变，只要原g本身是作用，就可有T_S(g)T_S(h)=T_S(gh)、单位元与逆元，因此固定S完全可能构成群作用。

若只允许若干不同coalition的一次操作，整个候选集合未必对复合封闭；输入依赖support、裁剪/重渲染、非可逆掩膜等还可能破坏群条件。Kimi的提醒有价值，但“一切局部support操作都不是群作用”的断言不成立。最稳妥做法是在群条件未验证时称干预族/intervention distribution，而非全部抹去群等变背景。

相似地，matched input-support intervention与causal abstraction里的内部变量interchange可能相关，但不是看到“替换”二字就自动等价；应具体比较干预对象、结构映射和可检验假设。

## 5. 防止恢复A时再次漂移

建议恢复顺序：

1. A-P0 文档/证据修正：任务拆分、heldout状态、headline和source ledger；先检查最新仓库是否已完成，避免重复施工。
2. A-P1 同匹配条件的coalition对照 + 新match确认 + 一个可解释task后果。允许条件化规律，不强迫所有架构/场景同符号。
3. A-P2 方法小实现：context/mode双读出及固定routing先行，评估是否能形成对现有方法有差别的贡献；禁止为了符合AMR缩写而保留无用模块。
4. A-P3 只有机制与任务共同存活再做第二域及更复杂learned gate。

这是**将来恢复的优先级备忘，不是当前Memory pilot的依赖**。也不额外要求外部预注册或一串人工批准。

## 6. 哪些报告内容没有采纳

不采纳伪精确中稿概率、对reviewer会给几分的保证、A一定有稳固兜底、B必须非单调才可能发表、有限检索证明无人做过、DPI给direct/staged排序、或2026论文一概属于未来虚构。相关意见的其他有效部分仍逐条保留。

**最终备忘结论：** A最需要的不是更多Jacobian相关性，也不是先堆AMR，而是把support差异、任务语义与可控任务后果连起来；方法目标保留，是否收缩论文形态留待证据与用户决定。
