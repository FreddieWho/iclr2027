# 05｜明确 GO / NO_GO，不追逐戏剧性

## 0. 决策含义

决策对象是“本轮是否把 Memory 提升为研究主线”。不是论文接收预测，也不是证明所有模型都存在/不存在 path dependence。

**终局只写 GO 或 NO_GO。** 内部可以一次补测，终局不保留 WAIT/MAYBE。NO_GO必须附理由码：SMALL_EFFECT（有效且足够精确）、NOVELTY（已实质覆盖/不足）、EVIDENCE（样本/外部验证/机制不足）、TECHNICAL（不可比或不可运行）。后两者不是科学证伪。

以下阈值是本项目的资源决策规则，不是文献标准或 ICLR 录取阈值。探索前允许根据任务分辨率合理调整并记理由，确认结果出来后不能为了 GO 降门槛。

## 1. 所有 GO 的共同底线

1. 真实、非mock数据；query-blind；相同 H、可解释且合格的实际预算；无隐藏回读/截断。关键对比有效配对率≥95%，reader oracle 能明显区分 no-memory；不能处处地板/天花板。
2. 至少64个新确认历史；建议96。子类型结论至少32个有该类型配对的历史；不能用64个QA替代64个历史。确认与探索独立，无结果驱动重调。
3. 除 C1/R1外至少一个独立泛化方向复现关键方向/机制：R2、C2或32个自然历史。总均值若会因模型反转，GO 只能是预先确认的条件性结论，不声称 universal。两端都只换同一模型别名不算。
4. 必须完成长度敏感性与 rewrite/same-K 对照；不是要求这些对照都显著，而是要求能确定当前 claim 究竟是哪一种。
5. 近邻对比表说明本次新知识，至少全文检查三篇直接近邻的方法/实验；不把“首次 repeated compaction”或“首创 retention/access split”作为通过依据。无法确认差异 → NO_GO_NOVELTY 或 NO_GO_EVIDENCE，而不是虚构文献不存在。
6. 有一条带出处的任务/策略含义和相应实测证据。比如同存储预算下延迟收紧可避免丢失更新；不能只有 summary ROUGE 的下降。

## 2. GO 的五条合法路径（满足一条即可）

| route_id | 足够的主证据 | 必要限制 |
|---|---|---|
| G1_ROBUST_PATH | 预设 direct/path 或同K schedule 配对 |ΔU|≥0.05，校正CI不跨0，新历史重复成立 | 可以单调；须有新颖且可用的调度/错误结构知识，不仅重复已知 decay |
| G2_CONDITIONAL | 预设类型/预算交互 |ΔΔU|≥0.08且CI不跨0；至少一子条件 |ΔU|≥0.08，并在独立设置复现 | 可以总体均值约0；不得事后挖数十子组；结论限对应类型/范围 |
| G3_REENCODING | R3−D 等重复改写效应≥0.05且CI不跨0，S/W对照指向可解释机制；轻量策略在新样本改善≥0.03且CI不跨0 | 降低原“独立bottleneck路径”claim；必须说明超过现有 drift/triage 工作的新知识 |
| G4_POLICY | query-blind固定/自适应schedule在确认上提高≥0.03且CI不跨0；或节省≥30%总费用/token工作量且性能CI下界≥−0.02 | 同final预算；不得读未来Q选路径；不把不同服务商折扣当算法节约 |
| G5_BOUNDARY | 至少两个预设path对比及第二设置的CI全落±0.03，仪器positive control有效；可简化系统并节省≥30%，或揭示明确的出现/消失边界 | 高门槛的正面等价证据；“不显著”不算；仅重复一个阴性均值不足以GO |

5pp指score∈[0,1]上的绝对差0.05。小于阈值的罕见灾难案例不能直接主线GO，可报告在附录并说明它为什么不足以替换当前路线。大效应但被服务商隐藏截断造成也不能GO。

## 3. 何时补测，何时停止

P1信号不显著且CI宽：允许一次扩大确认或选择一个事先列出的诊断扩展。所有格子地板：允许一个更宽B/更强reader。只有一个prompt上有效：允许一次structured/neutral交叉，不许调十个。

P2后只允许一次有具体可区分假设的扩展，最多两项（docs/02），总确认历史≤192；不做连续窥视直到p<0.05。补测前明确如果什么结果仍为NO_GO，之后必须结束。

## 4. NO_GO判定顺序

- 技术/权限/长度/评分不合格：NO_GO_TECHNICAL；科学结论写未评估。
- 新颖性查重确认已有同问题同关键证据，未找到额外知识：NO_GO_NOVELTY；不要因别人做过就称假设错误。
- 完成有效、足够精确的对比，全部预设候选处于实践小效应范围，亦无G5价值：NO_GO_SMALL_EFFECT；范围限定到测试的模型、prompt、L、B、任务。
- 其余没有满足任何GO路线：NO_GO_EVIDENCE。包括有限资源下CI仍宽、不足独立确认、只有合成模板记忆或机制审计未完成。不是“终身禁止研究”。

## 5. 决策产物

`templates/decision_input.json`记录每条候选效应、CI、n、真实来源及必要 audits。`scripts/decide.py`做机械一致性检查，输出二元判定。它不代替科学判断，novelty/generalization/length等通过项必须引用实际 `reports/*.md`、score文件或hash；不能为了让脚本GO手填 true。

最终一页必须回答：1) GO/NO_GO与route/reason；2) 最强确认效应及CI/n；3) 当前claim一句话；4) 对照排除了什么/没排除什么；5) 成本；6) 下一步是否仍值得投入。不能写伪精确中稿概率。
