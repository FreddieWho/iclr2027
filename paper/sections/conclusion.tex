\section{Conclusion}
\label{sec:conclusion}

Single-change supervision improves full compositional correctness only
when an endpoint rate would hide the difference. Atomic correctness can
coexist with a joint miss ($151/176$), and raw-coordinate recovery can
relocate errors. That relocation is not every repair: ResNet-18 is a
boundary. Input advantage is not positive interaction transfer.
Confidence inversion is a scoped side result.
