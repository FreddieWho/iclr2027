\section{Evaluation Protocol and Reproducibility}
\label{sec:repro}

\paragraph{One-shot fresh holdout.} \texttt{holdout\_909} was minted after
all discovery, pre-registered (E1\_PREREG), evaluated once in a single
uninterrupted run with fixed checkpoints, and archived as used; no new
metric has been or will be run on it. Discovery numbers and fresh numbers
are reported side by side with denominators and are never pooled.

\paragraph{Reporting protocol for repair comparisons.} Any repair
comparison in this line of work should report, on the same quartets:
own-conditional, baseline-fixed, and common-correct composition miss;
overall AB endpoint error; atomic pass rate; joint consistency $J$; full
repair and error migration (with the identity
$R_{\mathrm{endpoint}} = R_{\mathrm{full}} + M$); and matched-single
controls. Rationale: conditioning changes when a repair changes atomic
correctness, so single-denominator repair deltas can mislead. We claim no
priority for conditional measurement itself.

\paragraph{Sample banks and confirmation usage.} Mechanism analyses read
frozen sample banks (\texttt{bank\_dev512}, \texttt{bank\_confirm1007};
every model reads identical edits) with settings frozen on dev before
confirmation. \texttt{bank\_dev512} is a repeatedly analyzed historical
bank, not a sealed confirmation bank. Coordinate lineage does not support
an integer-ID leakage charge against it, and this paper does not repeat
that charge. Absence from the recorded training lists is not the same as
unseen by the investigators. The confirmation bank's per-claim first-read status is
recorded in the claim-source map
(\texttt{reports/caea817\_review/CONFIRMATION\_USAGE.md}): P1 analyses
first, relational-arm evaluation later; reading archived outputs is
tracked separately from training-time exposure. Thresholds, covariates,
metrics, and bootstrap units are recorded in
\texttt{reports/final\_closure/}. Parent-cluster intervals resample parents
and retain their associated quartets; quartet-level point estimates need
not equal an equally weighted average over parents.

\paragraph{Artifacts.} Code, reports, checkpoint metadata, rendering
scripts, and SHA-256 manifests are versioned with the paper. Large scene
arrays and checkpoints remain local assets; their public release is
pending, and a hash alone does not provide access. Restricted-access
football derivatives have hashes and conversion receipts. Coordinate
comparisons commonly use seeds 11/23/47; visual seeds are specified per
experiment. Match is the independence unit for football, and parent for
coordinate scenes. Historical recomputation entries are given in
\texttt{reports/final\_closure/REPRODUCE\_FINAL.md}.
