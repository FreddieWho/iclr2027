# AI Galaxy 远程实例经验目录

本目录记录本项目使用 AI Galaxy 远程实例时出现过的工程、计算和生命周期问题，作为后续租用、执行、回收和结算的独立操作依据。

## 范围

- 服务于 ICLR2027 Action-Mode Spectrum 项目。
- 只涉及点集运动数据、书法向量数据及其模型计算。
- 本项目不是生信项目；本目录及后续远程任务不得读取、更新或重建 `infra/bioinf-data-index/`，也不得引入生信数据。

## 文件

- `LESSONS_LEARNED.md`：已发生问题、原因、影响和修复原则。
- `CHECKLIST_BEFORE_REMOTE_JOB.md`：从租用前到退租后的执行清单。
- `INCIDENT_TIMELINE.md`：历史事件的脱敏时间线。

## 安全边界

本目录不保存密码、API token、私钥、完整凭据文件、临时认证文件内容或可直接登录的组合信息。主机地址、实例状态和费用必须以当次 provider 详情为准，文档中的历史端口只用于识别曾经发生过的混淆，不能直接复用。

## 事实来源优先级

1. provider 的实例详情、状态、GPU/CPU/内存和费用记录；
2. 远程任务的进程退出码、日志、输出清单和 SHA256；
3. 本地下载后的逐文件校验与审计；
4. handoff/聊天文字仅作为导航，不能单独作为“已完成”或“可释放”的证据。
