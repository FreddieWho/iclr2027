# AI Galaxy 远程任务清单

## A. 相关性与资源门

- [ ] 明确任务属于当前项目主线，说明为什么本地 CPU 不足。
- [ ] 确认没有把视觉路线、生信索引或无关大规模计算混入主线。
- [ ] 先完成本地最小可行 smoke；记录输入规模、wall time、RAM、VRAM 和输出大小。
- [ ] 估算上传、启动、环境核验、计算、下载、校验和释放时间。

若相关性不清楚、smoke 已足够快或结果不依赖 GPU：停止租用。

## B. 实例识别与安全

- [ ] 以 provider 详情为准核对实例唯一标识、SSH 端口、GPU、CPU、内存、状态和自动续租开关。
- [ ] 不复用旧 IP/端口、旧合同或“账号下唯一实例”的推断。
- [ ] 使用普通项目账号、任务专用 `known_hosts` 和严格 host-key 校验。
- [ ] 凭据不写入仓库、日志、命令历史或 handoff；临时凭据文件为 `0600`，完成后清理。

## C. 远程执行与 OOM 防护

- [ ] 先执行只读环境核验：GPU、驱动、Python、磁盘、内存和项目版本。
- [ ] 配置有界 chunk、流式 manifest/响应、`inference_mode` 和明确批大小。
- [ ] 给 16c32g 等低内存实例预留系统空间；不要让全量 JSON/delta/response 常驻内存。
- [ ] 任务启动、监控、收集和释放分开记录；不以 smoke 或进程仍存在代替完成判断。

## D. 收集与释放

- [ ] 远程任务成功退出并生成最终 manifest。
- [ ] 先下载 manifest，再下载结果和报告；本地逐文件 SHA256 校验通过。
- [ ] 检查核心输出是否完整、是否有 `NOT_RUN`/`INCOMPLETE`/`BLOCKED`。
- [ ] 校验前不释放实例；校验后按唯一实例标识执行释放。
- [ ] 释放后核对 provider 状态、费用/退款、账号运行数和 `kept_disks`。

## E. 关闭记录

- [ ] 记录本地 retrieval 目录、manifest、代码/配置版本和校验摘要。
- [ ] 记录实际 GPU 与实际 wall time；没有实测的性能数字标为估计。
- [ ] 记录生信隔离检查：本任务未读取、更新或重建 `infra/bioinf-data-index/`。
- [ ] 未经用户决定不删除远程结果或保留磁盘。
