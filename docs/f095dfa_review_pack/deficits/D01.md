## 要回答什么，以及为什么不是再堆模型
当前约6,849参数的MLP是仪器，不是强基线。检验“失效来自任务表述与训练覆盖”之前，先排除容量小、样本少、优化没收敛。旧DINO size sweep是冻结预训练特征的读出实验，不能替代本实验；旧小MLP变体也没有完整分开容量×数据×收敛。[R01,R02]

## 输入与固定对照
读取 `experiments/discovery_campaign/coord_mlp.py`、`r04b_methods.py`、`scenes/train_101` 和当前E银行接口。保留原配置作为历史锚点。新实验建议宽度64/256/512、特征维32/64/64；数据为原N、4N、16N嵌套父场景。默认先做“固定N的3宽度”和“固定256宽度的3数据量”，共享一个交点，共5格；不要自动跑满9格。数据由原oracle生成，不下载外部数据。另列解析oracle作为可解性上限，不把它算学习模型。

## 施工步骤
1. 实现统一trainer，显式保存每个arm初始化、预处理、数据清单和优化轨迹；原模型与新增模型都记录参数量、前向次数和训练时间。
2. 用普通静态开发集选择停止点和有限学习率集合，不用AB、CCM或J挑epoch。可以延长训练解决未收敛，但报告等步数结果和各自收敛结果，不能混为“同预算”。
3. 每格起步3个独立训练seed。相同输入维度的修复对照从同一初始化或同一基线checkpoint出发；改变宽度只要求同数据与可比训练合同。
4. 每格测无flip与同一份flip数据；先确认历史锚点数值能复现，再展开成本较低的剩余格。
5. 将组合风险对原子准确率、训练数据量和参数量分别作图。允许挑相近atomic区间比较，但所有格原始结果必须列出。

## 指标与必要证据
静态训练/开发误差，A/B边际准确率，atomic-pass覆盖，CCM、全体AB错误、J、原子保持下的完整修复、误迁移、D02的orbit指标。报告样本量与parent配对区间，训练seed单列。不能只给“更大模型CCM仍高”而隐去它只留下了很小的条件子集。

## 结果如何处置
- 强且收敛的普通模型低成本消除大部分失效：接受反证，缩小“普遍缺陷”叙事；可以研究效率或数据边界，但不要继续换更难测试集救高失败率。
- 相似atomic表现下，J与更新风险仍差，关系/对称性臂稳定改善：这是后续机制实验的可信起点。
- 训练未收敛或出现数据生成差异：未决，不宣布容量无效。
不要求任意85%门槛；是否有足够合格实例与可辨别效应，按实际precision和全体表现判断。
