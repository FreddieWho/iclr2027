## 1. 优先级覆盖
本指令覆盖旧 TODO/B30/上一轮 REVIEW_ACTIONS 中关于本轮研究优先级的建议。它**不覆盖**数据许可、费用授权或保留真实实验记录的要求。
- 不先执行上一包的“数值与强基线闭合”“耦合证据加固”“旧稿行政冻结”。那些不是新探索的前置条件。
- 不复活旧 AMR v1–v6、CAP、教师、nomask、JGCL 的配方竞赛，不重做已结束的 μ 阈值。
- 不把 8/8、34.2%、37.7% 等历史数字重新包装当成本轮产出。
- 不恢复 Memory，不等待旧 gate，不新增审批/预注册链。
- 原有失败证据保留，但不要求新路线解释全部历史失败。

## 2. 第一个工作循环必须落到计算
读取本包；用 `bootstrap_run.py` 找现有数据、模型、JVP、训练和评价入口。若本地状态比基准 commit 新，读取新增结果避免重复，不回滚仓库。
写一个短的 `CAMPAIGN_STATE.md`，然后立即开始 R01/R02/R05 的可执行试验；R06 的模拟数据试跑可作为第四个低资源任务。不要交付另一份头脑风暴代替运行。

你可用 Codex 作总控、现有已配置 worker 工具作实现者；不得猜测或硬编码 provider/model 名。worker 不可用时顺序执行，不以工具配置阻塞科学问题。

## 3. 研究组合
阅读六个 `routes/R*.md`。建议资源排序而非硬门：
1. R01：同边际、同能量、同质心的依赖变化；目标是风险跃迁或模型排序变化，不是再算一次 Spearman。
2. R02：关系改变而表示保持的反例；已有 over-invariance/metamer 研究，必须落到可控构件协同与新任务后果。
3. R05：冻结骨干、关系反例驱动的度量/读出重配置；与同监督预算普通度量学习竞争。
4. R03：少数源端模式跨模型/场景迁移；不能在目标端重选后称零查询。
5. R04：固定个体增广分布，优化协同分布的 minimax 训练；非温度/学习率扫参。
6. R06：真实再仿真的长期后果；不把两条真实轨迹当作未观测反事实。

R03/R04 可用随机初始模式库先构建，**无需 R01 达到“显著”才获准开展**。六条路线均值得首轮探索，但不是每条都值得规模化。

## 4. 自主权
可以改现有任务、引入本包里的受控关系任务、使用一类可获得的冻结视觉编码器、引入可再仿真的相互作用系统。可以编写新 adapter、换干预族、换任务读出和新方法；可以基于失败提出本包以外的一条更强替代路线，写清与已有工作的区别后直接做小试。

允许探索中途改变设计；在记录中说明“看到了什么→为什么改→改变了哪个科学变量”。不要求先取得 p<0.05、10 seeds、外部确认或审稿人认可。

**停止的依据是信息价值下降，不是单次阴性。**无效实现先修；真实阴性可换任务语义、作用方向、联合分布族等概念变量；没有新机制理由时才停止。普通学习率、温度、margin 网格不属于概念迭代。

## 5. 最低必要规则，仅用于防止伪发现
- R01 的各组必须真有相同个体边际、能量和声明过的质心约束；不能用对一种方法有利的单独过滤。
- 区分“标签不应变却预测变了”与“标签已经变了但预测没变”。有 oracle 就重算，不能沿用错误标签。
- `J^T J` 是有限扰动的局部代理，不是任务风险真值，也不是学到语义交互的自动证据。
- 同一结果必须用同一层/距离/样本集合比较。旧评价函数有问题时在新分支就地替换，**不启动全仓审计**。
- 失败率、迁移率、加速比、低成本修复要有分母和成本；不报近零分母倍率。
- 记录尝试过的路线。可根据探索选故事，但不能将事后选择写成事前预测。

## 6. 资源与并行
默认最多 3 个计算密集 worker 并行，模型独占 GPU，不限制轻量文献/写作 worker。优先旧 checkpoints、小型模拟和缓存表示。新的付费 GPU/API/数据要服从现有明确授权；没有授权时递交一次清楚的费用请求，其他本地任务继续。
旧“剩余8轮”不自动等于新费用授权，也不要求花完。训练规模可增加，但原因必须是检验新机制而非抬高旧指标。

按 `06_EXECUTION.md` 输出每轮极简结果卡、样本级明细、新的成败判别图和代表案例。每条路线必须写：
- 原先默认的判断是什么？这次改变了什么？
- 哪个事实一旦成立，论文摘要第一句话就该改？
- 最强的替代解释或已有方法是什么？本轮什么对照能分开它们？
