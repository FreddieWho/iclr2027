# 第二施工单：有提升价值的既有路线

基准同总控。先修相应R项，不要求等待全部R项完成才启动不受影响的工作。以下是6个可独立交给worker的优化包，优先 O02/O03/O05；没有固定的“必须提升10pp”或“未到90%就不准评价”门槛。

## O01｜D01/U07/D08：训练配方与表示的数据效率分开

### 科学问题
在可靠优化之后，成对几何输入是否仍比原始坐标需要更少的标签改变例子？当前优势不能靠raw塌缩来证明；PCT救援也不能在起点不同情况下被归因到保护loss。

### 执行
1. R03生成所有候选模型都未见的新parent评价池；旧dev512作为历史stress诊断并保留，不再叫未见parent。
2. 先只选raw与sixdist两输入、一个足够宽但可CPU训练的主干。基础数据N/4N，flip子集0/25/100%。已有有效格复用，受训练合同影响的格重跑。
3. 独立管理模型初始化、采样/数据顺序、flip子集和增广seed；同一模型方法单跑/批量跑应输出同一个初始state哈希、同一训练batch列表。保存loss曲线和实际step数。
4. 给raw和six同等数量的低成本训练候选，例如Adam(.01/.003/.001)＋一个收敛稳健的配置；仅按static/single开发误差选择。不要根据E-J为某臂选best seed。完整披露失败配置并区分最优配方比较和等配方比较。
5. Scratch与warm-start作为两个明确因素。若从clean开始，plain continuation、PCT式保护、hard-label replay必须同起点同训练步数。恢复后重新算J、原子保持、迁移，而不是只报告trainloss。
6. oracle成本三账本：实际查询候选数、保留标签数、每轮forward/gradient数。25%子集在挖全池以后选出来，最多证明保留数据效率，不能声称节省75% oracle查询。

### 读法
若六距离在稳定raw强基线上仍有较大优势，可进入主结果。若raw充分优化追平，也有重要信息：旧表现主要是训练接口而非容量规律。结论不随“是否命中预期”选择性保留。

### 产物
`O01_FACTORIAL.csv`、parent配对CI、失败/塌缩分母、初始哈希与训练轨迹；一张数据—标签改变覆盖响应面。禁止把N/4N训练规模当两个独立测试集。

## O02｜U10：把跨任务预测从计数口号升级为有边界的规律

### 优先保留
T1六距离+flip J约.75，T2约.998，是当前最强的外域正结果。T2原始J尺度I为负不削弱其最终性能，但否定了统一的超加性交互。

### 执行
1. 完成R02 typed归一化重训；完整四臂含raw、raw+flip、distance、distance+flip在所有任务同池重算。
2. 保存所有parent的三个/四个状态分数、label、编辑、原子保持、J、R_full/M；按parent重采样四臂一起计算I，不能只有汇总命中判据。
3. 多标签方向分层。T2距离输入只有3个距离而非6；明确“角色指定的成对距离”这一共同原则，不把代码arch='six'误写成输入维度相同。
4. 参数/优化预算匹配是必要对照；typed更大但更差不能自动“让阴性更强”，它也可能更难优化。先看train与single-dev拟合，再解释残余差异。
5. 不改T2阈值/难度使I转正。可追加新、未用任务难度区间（如原有margin区间的自然跨度）检验I随headroom变化的预测，但作为新的探索，不回填原claim。
6. 可加一个刻意的边界任务：标签依赖有向手性时，纯距离不能区分镜像；额外加入有向信息后可区分。只作为表示适配性反例，不声称该初等不可辨识定理是原创。

### 文章落点
主表用“源任务发现→T1正互补实例→T2高性能但负I边界”。统一说特征和监督的效果依赖任务、基线难度与尺度，不能说任何关系任务均超加性。

## O03｜D04：补成真正可解释的标准视觉模型repair实验

### 当前缺口
现有pretrained/random/head-only都用clean+flip数据；没有同架构static-only，因而不能估计flip的修复效应。224是上采样，BN probe未纯冻结。

### 执行
1. 固定一个标准ResNet18，不扩四种backbone。按R06修BN和独立RNG。
2. 最小矩阵：pretrained vs random × static-only vs same-base+flip。主输入取已验证能胜任任务的224上采样，64保留尺度对照。每臂至少三个独立训练seed；有训练不稳先用single-dev公平调优。
3. same-data-static控制很重要：若候选方法用pair/aux，所有对照看到同样原图与终点标签，只有结构或目标不同。
4. parent严格划分，检查旧`quartets_eval`是否复用train101父场景与near duplicatedrender；新parent测试保证物理状态先分再render。前向保存logit而非只保存0/1，支撑P1/阈值诊断。
5. 主比较：J、baseline固定110→111、错误迁移、旧正确原子回归、static、CCM及其分母。编辑前置信评价使用起点，不能用终点。
6. 只有相关before/after差成立才说“repair迁移”。单个视觉模型任务適配做得好，本身是强基线，不等于方法迁移成功。

### 推进
若完整repair成立，可取代一部分旧tiny-CNN篇幅进入主文。若大部分现象消失，明确提供了模型/训练条件边界，不能再写所有成熟视觉模型都会同样失败。真实信息/尺度机制由N02接力。

## O04｜U03/U04/D10：让诊断真正指导下一次干预

### 约束
S定义在最终标量score上，是encoder与head共同性质；J*是使用test真值选出的诊断上界，不是部署准确率。

### 执行
1. 4类冻结encoder上统一缓存特征；训练集拟合特征标准化/whitening，冻结到eval。给线性head一个可靠的凸优化对照（如正则logistic/LBFGS），并报告优化收敛，不只Adam300轮。
2. 同一个新head初始化及数据集，static与flip交叉训练；MLP小头给予同等开发选择预算，不用单个16hidden失败宣布所有非线性无用。
3. 每臂独立报告S/J*/J。对四臂的S变化和J变化做同parent配对分析；比较不同head是否能改变S，从而直接检验“encoder主导”的范围。
4. 原始任务中剩余S−J*很大，适合检验跨场景score可比性：从train-only带状态标签的不同parent配对中学习一个单图readout；与同样状态标签BCE、同样额外步数对照。若增加pair-ranking或context-conditioned校正，必须同一函数用于任何单图，不能读qid/目标标签/该quartet阈值。
5. 最终在新任务或新模型预先写清“本干预主要影响哪一段”，再评价。一个初等分解变成有用的科学诊断，需要外部预测，而不是只给已有现象命名。

### 产物
readout固定主干哈希、solver日志、每段配对差、开发拟合/评价分离的阈值结果。D10完成R09后作为下游回声，不反推“概率本身有问题”的全称结论。

## O05｜D06/D07/U09：足球从已选传球转向候选关系与部分观测

### 两级任务，禁止混称
第一层：真实坐标上的候选通道几何代理。真值可由完整坐标算出，不等于真实传球会成功。
第二层：从自然缺测/有定义的遮挡与噪声输入，推断完整关系。此时存在实际统计推断需求。

### 执行
1. R08修时间/角色/真正E构造。保留真实已选传球，但另建同一时刻所有合法接球者候选，限制球队/场内/距离等条件并记录抽样权重，不伪造counterfactual outcome。
2. 受控几何主变化至少一端点变量与一阻挡者变量共同参与；先证实oracle逻辑允许“各自保持、合起来改变”。不无限扩大扰动。
3. 自然连续轨迹与受控路径分开；逐比赛划分训练/开发/测试，时间窗口跨缺测/半场直接断开。到达新类别、误报警和提前/滞后报告真实秒数，不只两帧。
4. 完整坐标基线必须包括解析几何；不期望神经网络击败提供同真值的oracle。部分观测基线包括最近值、线性插值或合理状态估计后解析计算；与typed graph/关系编码模型比较。
5. 部分观测不能只注入任意高斯噪声把基线变差。报告真实缺测模式，人工掩码是明确的受控压力测试；使用同一完整标签，不使用未来不可得坐标补输入。
6. 首批复用现有可用比赛。D07不需要先构造E；U09不需要知道未发生传球的结果。若关联目标不存在common support，如实限定而非宣称原则失败。

### 可能主结果
“结构＋变化训练从完整几何仪器迁移到不完整真实tracking的关系判别”。只有该结果成立，足球才承担主贡献；否则回到辅助真实坐标验证。

## O06｜D05：原生多模态行为测试可以独立推进

U06辅助头失败不构成D05停止依据。该包属于可选外部桥，不为满足模型名气而硬上。

- 使用已连接且在用户批准费用/权限内的一个成熟原生多模态模型；checkpoint/API版本、图像处理、输出解析、费用固定并记录。实际可用provider由agent查官方文档，不在此指定过时modelID。
- 每个状态独立新请求，同一提示不泄露其他状态/答案/组合类别；原子、AB、base相同渲染分布。保存原始响应，严格区分parse failure、拒答与模型错误。
- 同时给自然可理解的基本几何/关系识别sanity；当前准确率和置信来源若不可比，不强行套小MLP logit P1。
- 报整体J、条件CCM与原子分母；不以85%人为门槛抹掉结果，但原子不足时不得解释成组合专属机制。
- 从小样本可行性到固定验证集，只依据输入/解析是否可用和误差不确定性判断，不根据正阳性筛模型。即使强模型没有同类缺陷，亦是有效外推边界。

D05若未执行，paper写未测试，不写大模型推广失败。
