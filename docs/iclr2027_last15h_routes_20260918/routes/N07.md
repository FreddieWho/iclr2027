# N07｜不是更多反例，而是覆盖更多种语义转折的小教材

研究优先级：中高，效率型大数字。默认worker：W3。

状态：PROPOSED / NOT RUN。下文是新实验设计，不是已获得结果。

## 新问题
旧预算曲线只随机拿25/50/75%的翻转对；旧“离新类训练点更远”选择没有净收益。本轮改问：反例数量是否远大于其有效语义方向数量？

## 最小实现
对N01候选边界对记录语义类转换、被编辑构件、合法编辑坐标中的单位跨界方向和局部背景。先用分层覆盖+k-center选择16/32/64/128对；第二版才尝试D-optimal/logdet方向覆盖。对角点/多边界案例使用事件类型而不是不稳定单一法向。
相同例数比较随机翻转、旧d_new选择、原始输入k-center和转折覆盖。所有组合复用同一候选池，父场景数单列。

## 数字出口
达到现有完整flipmine同等误差所需训练对数/微调计算，相对随机反例的学习曲线。若先给全池打完标签再筛选，只能说训练样本/优化开销更少，不能说oracle或人工标注便宜了。真正标签效率需要把筛选过程中消耗的全部查询也算上。

## 和N05关系
N07测试压缩的结构，N05测试压缩教材能否转移，是两项独立假设；可以一成一败。不要求先得到N05阳性才做N07。
首轮上限90分钟，用已有有标签池可立即试；不预设“10倍”，不把小集训练变差后加很多epoch的成本藏起来。
