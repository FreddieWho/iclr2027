# A｜首要路线：把不变性、跨对象交互与几何特征分开

## 科学目标

不是重新证明“对称性有用”。问：
**在具有足够表达能力的同预算模型中，合法任务不变性是否使single-edit监督更有效地转化为完整联合正确性？收益还需要额外几何计算吗？**

现有动机：L015的G8特征J均值.563、距离特征.419、permaug.286、raw.091（同一历史银行的10seed）；但G8新增中点距离与归一化方向叉积，旧集合网络又在段间可加。因此现有比较无法分离两项解释。

## A0：必须先做的表达能力审计

原代码：experiments/f095_campaign/u01_models.py:TypedPairMLP；experiments/e1a933_review/leads_l014_l015_l006.py:G8SetMLP。

原式 z=ψ(h_AB)+ψ(h_CD)，rho为Linear；所以logit=a(AB)+a(CD)+b。
06的4例棋盘真值不能由此函数类拟合。用真实仓库模块重复混合差分恒等式；将结果写为确定的架构限制，不是训练数据上的新普遍定理。

第一修法：只把最后rho改为一个含非线性的MLP。
例如 rho: Linear(d,k) → GELU/ReLU → Linear(k,1)。
保留段内角色、交换对称、相同数据与监督。不要把四点无类型sum作为有效模型。

第二有效对照（可在第一修法难优化时选用）：
用共享函数q处理(h_AB,h_CD)与(h_CD,h_AB)，平均其输出；q必须非线性地同时看到两段。
它明确保留段间交互并对段交换不变。两个端点的段表示也需合法交换不变。

这些均是标准关系/集合建模思想，不命名为原创新网络。

## A1：最小有判别力的训练矩阵

在同一训练、single-dev、新parent-test银行上跑：

|模型|用途|
|---|---|
|raw MLP|正常强基线，不刻意弱化|
|旧加性typed|表达能力负控|
|修正后的交互typed|最小架构干预|
|6个有序点对距离＋同MLP|原有正对照|
|8维unsorted丰富几何＋同MLP|控制中点/角度信息，不做排序|
|同8维sorted G8几何＋同MLP|分离相同几何信息基础上的不变处理|

每个模型先clean-only / single-flip两种监督。可先3seed探索，再对最终比较用5–10seed；不要为所有明显无效臂重复10次。
raw与各臂都给同样的有限LR/优化器选择预算，以static/single-dev选；另报同recipe敏感性。
旧加性typed不需“调到收敛救活”，它只能作为受限函数类负控。

8维unsorted量明确为：两段长、四跨段距离、中点距离、|sin夹角|。
sorted版本与其使用同样连续量；二者可能有不同信息保留，所以只能说是该具体不变处理，不可直接声称信息完全相同。
如果sorted有优势，追加一个保留完整关联关系的有限G8轨道规范形式或全群score平均对照；不要独立排序所有边后宣称得到了完整商空间表示。

归一化：几何量处理后固定train统计；typed/raw角色交换使用共享xy或角色共享stats。

## A2：公平与强基线

- 记录实际参数、训练MAC、推理MAC；groupavg记8×前向成本。
- 修后非线性增加参数时给参数匹配raw；不要为了绝对等参数把唯一交互层削掉。
- 继承O01可靠数据/优化器合同，所有臂在同一新池评估。
- 不使用旧dev512选择最终claim，然后仍称其“确认”；它适合工程与发现。
- 训练标签翻转样本、普通独立标签状态与preserve数量清楚；不能用不同采样合同的历史checkpoint充当严格2×2。

## A3：最小必要评价

J3、J4、A/B边际和atomic_joint、AB准确率、CCM及分母；固定baseline110流向、baseline111回归。
身份标签J、群平均J、每群元J、原模型all8成功率必须分开。对严格不变模型，零摆动是设计保证，不是8次复制。
估计表示×监督交互I，但既报原始百分点又报边际效应；T2负I保留，不事后换尺度。
S/J*只作分数诊断；别把代数恒等式、或者优化后的最优测试阈值当新可部署方法。

## A4：先提出可失败预测

P1：旧加性网络无法完成棋盘真值；修后有表达能力，不保证实际优化必然成功。
P2：若旧阴性主要来自段间交互缺失，修正应在匹配监督下提高J而非只抬AB。
P3：若G8优势主要来自新增中点/角度量，unsorted-rich应明显缩小sorted-rich的差距；否则排序/不变组织仍有额外效应。
P4：若合法不变性有实际训练价值，而不只是零摆动，收益应在新parent及重新命名平均下保持，而不是只在identity约定更好。

## A5：已有跨任务，不再随意添题

源任务得到可解释比较后，在T1/T2上验证同一设计原则；角色与合法群按任务定义，不把源码完全不同的typed臂统称一个模型。
源任务“段间加性不够”不是T1/T2的自动证明。每个架构先做可表达的最小反例/函数检查。
三任务共同证明的可以是输入优势；不能把交互符号一致预设为成功必要条件。

## A6：结果分支与论文价值

- 修后的普通交互网络接近手工几何：旧“手工特征不可替代”撤回；可报告具体关系计算不足与恢复。若这只是复现已知RN能力，则当基线/解释，不冒充新方法。
- sorted-rich仍显著优于表达充足的模型：进一步报告何种未见编辑/噪声/数据量下有效，形成受控数据效率结果。
- 六距离和丰富几何都足够，排序只去摆动不提升J：不写对称性导致准确率提升；保留其正确性约束价值。
- 强基线已基本解决：承认此任务存在廉价解决方法，论文缩为评估/有限数据研究；不要制造更难测试来维持盲区。

完成标准不是所有格子阳性，而是至少一个竞争解释被真正区别。该路线如只有“加一层就好了”，不足以单独把论文抬成方法论文，需要B的独立验证。
