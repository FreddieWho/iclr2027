# 论文主线与审稿人吸引力整改

## 核心决定

从“失败现象全集”改成“完整修复何时发生”的受控实验论文。
不是删掉不利结果；是用一份统一结果表说清楚不利结果的范围，把迭代历史与流水账放附录。

## 版本A：现有证据足够的安全故事

1. 相同场景的A/B/AB提供完整修复与迁移的区分。
2. 旧raw表示下终点增益主要迁移；距离输入下更多转为完整修复，合理选型后优势仍在。
3. 原子条件结果、P1、下游效用分别有条件边界；不能用一个准确率替代。
4. 标准ResNet18在同一类受控视觉任务中确实能获得完整修复，说明不是所有网络都同样“盲”。

贡献最多三条：可审计测量；表示/训练条件的实证比较；胜任视觉系统上的独立行为验证。
P1作为有记忆点的副发现，不能继续在Introduction称唯一中心，同时摘要主体讲结构修复。

## 版本B：仅A/B新证据支持后

若修正后交互对照与同信息对称对照给出可靠区分，并迁移到视觉系统：主张“任务兼容关系计算影响single-edit监督转化成完整一致性的效率/流向”。
这是条件性科学结论，不叫普适定律；不把标准RN/DeepSets修改命名成全新方法。
如果A修正后普通模型就解决任务，诚实重构为有限数据/评价论文，不保留不成立的强机制。

## 审稿人攻击脚本

Reviewer-A：这不就是已知关系网络/特征工程？
回答必须是：明确新的预测和配对实验，而不是给标准模块换名。

Reviewer-B：弱小MLP不值得研究？
回答必须是：优化/合理交互强基线＋胜任的ResNet证据；承认有廉价解时收窄问题。

Reviewer-C：几何测试太人工？
回答必须是：受控科学对象能精确检验训练原则；没有自然任务效应就不声称广泛应用。足球不能装饰成实用成功。

Reviewer-D：大量自适应探索之后只剩阳性？
回答必须是：完整候选、选择规则与最终新parent验证；只把最终1–2条主claim用于确认，不列243tests作为科学显著性。

每次改稿使用一个Claim→Figure/Table→结果文件→脚本的映射。正文应读起来像最终科学报告，不是撤回历史声明的审计日志。
