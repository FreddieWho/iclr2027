## 使用顺序

1. 总控先读 `00_REVIEW_AND_CLAIMS.md`、`01_MASTER_PROMPT.md`。
2. 把 `02_A_RELATIONAL_STRUCTURE.md` 交给坐标/结构worker：主优先级。
3. 把 `03_B_VISUAL_TRANSFER.md` 交给视觉worker：先复用已完成结果，再进行与A直接相关的验证。
4. `04_C_COMPUTE_FRONTIER_OPTIONAL.md` 是条件性备选，不是第三条必须完成的大主线。
5. 写作worker同步执行 `05_PAPER_RESTRUCTURING.md`。不要等所有探索完再改正文。
6. 实验前先跑 `checks/test_interaction_witness.py`，理解新发现的表达能力问题。它不是原项目实证复现。
