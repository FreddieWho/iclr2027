# B｜第二主线：在胜任任务的视觉模型上验证同一个结构结论

## 为什么继续、为什么不继续旧搜索

已完成的GPU ResNet18足够作为起点：canonical224协议下J约.68，static→flip的完整修复多于迁移。
N01改善几何误差但没有稳定J额外收益；N03的真几何替换head时J为0，也未优于BCE强基线。
所以本路线不是“把aux权重再扫一次”，也不回到冻结DINO读出。

## B0：先把既有视觉证据变成主文可用比较

复用VISION_GPU_RESULTS的同backend、同renderer、同test parents、同预算四臂：
pretrained/random × static/flip。
补齐统一per-parent表：J3/J4、原子、AB、完整修复、迁移、111回归。图中明确该系统多数endpoint gain成为完整修复，不能与tiny raw迁移占优拼成一个普遍规律。
P1只在预测前可用的分数上评估，保留current/flip条件区别；若无反转，报告边界，不换一个更糟checkpoint。

新增结果必须使用新parent测试；已暴露159q和N02的178q可作工程，但不能混表或互称同条件提升。

## B1：由A产生一个结构对照，而不是无条件造新方法

主问题：**在感知已经足够的情况下，关系的联合计算是否影响完整修复，而非仅仅当前准确率？**

建议比较：
1. ResNet18直接分类（已知强基线，给同等选型预算）；
2. 同encoder＋可观测性匹配aux（旧N01强对照）；
3. 同encoder＋A中验证过的交互读出；
4. 同输入段表示，但去掉跨段非线性（加性消融）。

3/4的视觉段表示必须有共同定义：以图中实际可见的红/蓝段为角色，可用颜色分组的patch/heatmap读出；端点没有命名时用段内集合/匹配损失，不偷偷引入不可观测A/B编号。
oracle几何只在训练作为明确的特权监督。推理不得输入坐标、AB真值、对应单编辑答案或组合ID。
如采用图像分割/拟合产生对象，必须同时报告经典颜色分割/PCA/线拟合＋解析几何基线。易任务上解析方案最好不构成项目失败，而限制实用方法claim。

## B2：避免旧N03的“几何名字、任意潜码”问题

默认不再端到端同时自由学习几何瓶颈和任意head。
一种可选且直接相关的实现：
- 在训练坐标上训练A的有效关系head，验证它在真实几何上的任务能力；
- 冻结该head，视觉前端学习可观测、物理可行的两段坐标/关系；
- 先以匹配几何目标训练，再用同一head的BCE作低权重微调；所有选择在singleton-dev完成。

这只是实现选项，worker可以用更简单对象交互模块替代。必须说明为什么不同于旧N03，不能把换名当新实验。
几何输出限制在合法坐标范围，保留匹配误差、真几何替换、微小噪声敏感性和源head性能。真几何替换是诊断，不按测试标签优化。
几何不准且head不能处理真几何时，只能判接口未建立，不能解释为“模型不需要关系”。

## B3：测试集要区分来源，不制造失败

至少两个条件：
- 同renderer的新parent基本泛化；
- 开发前选定的一种观测变化，例如受控遮挡/线宽/背景/采样，而非看到结果后挑最有利style。

只对仍可从观测辨识标签的样本作强机制解释；全部样本仍保留总体结果并单列不可辨识/解析失败。
若图像实际不变却oracle标签变化，属于观测歧义，不算模型盲点。
每个parent最多固定量编辑，保留未筛选候选的产率；不得按模型错误挑确认集。

## B4：核心比较

主指标为相同single-edit训练预算下的新parent J3与R_full/M；同时报告static/atomic和111 regression。
以训练、选型与推理MAC分别记账，不只比较参数量。模型/数据初始化分开，BatchNorm冻结行为明确。
不用任意.85原子门槛决定是否允许看结果；在低原子区域报告联合性能，并限制“组合专属”解释。成熟模型表现好时不要再换弱模型制造现象。

## B5：合理升级与停止

若交互结构在同等感知误差、同预算下稳定改善J/full repair，并在预设观察变化中保持，可以成为机制实例或方法性扩展。
若只提升辅助MSE而任务不变，停止aux线路；不再扫十个loss。
若直接ResNet已同样好，可发表的是可靠性边界与足够条件的实例，而不是强行宣布新架构优胜。

若首个视觉结果清楚且值得移植，可增加一个独立标准骨干（ResNet50或一个固定ViT中择一），目的是验证干预，不是模型名单扩充。GPU允许但不是必须把模型放大。
原生VLM继续只保留单个Qwen2.5-VL-3B的范围限定；不需要为“实用性背书”再跑多个原子能力不足的VLM。

## 交付

一张四臂视觉修复表、一张与A严格对齐的交互消融图、逐parent结果和清晰迁移/不迁移结论。
不要最后只报“比baseline高2分”，必须回答源任务发现的哪个结构因素在视觉条件下仍有效。
