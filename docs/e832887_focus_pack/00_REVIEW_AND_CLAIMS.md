# 全文竞争力与科学结论

## 1. 总评

当前已经具备一篇有价值的受控实证论文的材料，不再是“只有几千参数模型的失败展示”。但目前尚不是一个强机制/强方法论文：最强新结果与第一页的中心不一致，若干已知思想缺少直接强基线，部分因果解释仍超过证据。

我的判断是：当前稿处于边界竞争区间，不能因实验数量多就视为稳接收。审稿人的主要疑问将是“这些受控结果带来了什么可迁移的新知识”，而不只是模型参数量。
接收概率没有可校准数据；任何数字只能是主观风险区间。本包不把新增实验数量换算成概率。

## 3. 新发现：当前一个重要结构对照不是合格的关系模型

源任务 `TypedPairMLP` 与 L015 `G8SetMLP` 在段级编码后直接求和接线性rho：

f(S,T)=wᵀψ(h(S))+wᵀψ(h(T))+b = a(S)+a(T)+b。

这对一般两段相交不具充分表达能力。两条水平段分别位于上下，两条短竖段也分别位于上下，即可生成真值 [[1,0],[0,1]]。对任何加性打分有 f11+f22=f12+f21，无法把两个对角格判正且两个非对角格判负。见06和测试。

影响范围：原源任务typed/g8set/g8wide的失败，不能作为“可学习不变关系结构不如手工关系表示”的干净证据。不要波及融合结构不同的TypedTri/TypedDisk，也不要撤销距离模型本身的正结果。
这是本轮优先整改项。它不是“新法已成功”，更不是新定理；修后的模型必须实际验证。

## 4. 收缩后的主问题

推荐：**单次变化监督何时能改善完整组合正确性，而不是只改变错误的位置？输入表示和跨对象交互在其中承担什么作用？**

主证据：
1. 定义并测量完整修复/迁移；
2. 在合理表达能力与预算控制下，比较输入组织和关系计算；
3. 在一个已胜任任务的标准视觉模型上进行同口径检验。

P1作相关但独立的可靠性边界；P2和足球作为外部边界/附录。不要强行串成因果链。

## 5. 主线取舍

主文必留：E定义、J3及迁移、合理强基线、距离输入正结果、标准视觉模型完整修复。
主文候选：修后的关系结构干预、L015新池复现与因素分解。
可压缩：P1、连续路径证据、样本保留效率。
附录：O01全部网格、各种失败recipe、原生VLM阴性、N01辅助误差、P2和足球完整边界。
本论文暂不扩：足球方法赛、VLM榜单、辅助loss搜索、N03自由潜变量瓶颈、AMR/谱/半径/边界角度复活。

## 6. 可能影响评审的写作问题

- Introduction仍称P1为中心描述发现，但较强结构/优化/视觉干预散落在后文和附录。
- main.tex中Figure 1仍是TODO；真实实例首图应从固定总体以明确规则选择，展示完整修复和迁移各一例，不用于效应估计。
- Discussion仍有“原生多模态未测试”残留，与O06已完成冲突。
- N02报告把J/atomic_joint写作CCM；在本文它是条件正确率，不是CCM漏判率，必须统一schema。
- 经典像素几何基线.717属于159q银行；不得与另一178q银行上的.91或其他renderer混排。
- 新R03坐标血缘结论：dev512父坐标并不在N/4N/16N训练列表中；旧整数ID泄漏指控应撤销。它仍是反复分析过的历史银行，未见训练不等于未见研究者 [R11]。

## 7. 审稿人吸引力如何提升

不靠更多百分比。要让读者记住一个比较：同样的监督，某个模型只是把错误移走，而修正的关系计算/表示使完整正确性真正提高。
最少的有效新增证据是一次能区分竞争解释的结构干预，以及一个标准视觉模型上的预先定义验证。方法组件可以是已知的，但发现必须比“距离特征有用”“关系网络会做关系题”更具体。
