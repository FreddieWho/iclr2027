- route1的新源池（1414 E/389 parent）再次支持特定排序的收益。但其T1/T2结果不能直接给出排序迁移的有效否定：有输入语义、结构与采样合同问题，见01。

## 3. 最重要的新信息：T1有明确的表示碰撞

三角形顶点固定为：

```
V1=(-0.75,0)
V2=( 0.75,0)
V3=(-0.375,0.75)
Q_inside =( 0.1875, 0.09375)
Q_outside=(-0.1875,-0.09375)
```

Q_inside的重心坐标为(.28125,.59375,.125)，Q_outside为(.71875,.40625,−.125)，标签相反，两者不在边界上。

`common_runner.rich(T1)`再独立排序triangle edges与Q-to-vertex distances后，两场景特征完全相同（本反例的坐标均为二进制可精确表示，float32也可复核）。额外质心距离和代码中命名为`sine`的量也相同。有序距离能区分它们；合法S3作用下整套距离一起规范化也能区分。

这是“当前排序不是普遍任务充分表示”的构造性证据。对人为各占一半的这两个状态，任何仅读该表示的确定分类器最多答对一半。**它不证明原随机银行存在相同比例的Bayes误差，不证明T1阴性全部由此造成，也不证明源任务八维排序具有相同碰撞。** 原银行中的近碰撞频率、误差贡献和修正后的学习收益必须另测。

## 4. 战略收敛

本轮只保留两个主研究问题：

1. 哪一种消除无关命名的处理，保留了决定关系答案的对应关系？
2. 在接口一致时，学到的关系计算能否被保持不变、接到新的观测前端上？

计算配置/空间采样作为独立备选，不再与前两条强行合成统一机制。足球、原生VLM、P1、P2不另开大训练线；但若现场有明确、新且可检验的证据，可用小预算记录和测试。

## 5. 当前论文能说什么

受控编辑与同quartet的full-repair/migration测量仍是主资产。标准视觉分类器可以实现完整修复，说明raw tiny模型的坏修复不是普遍定律。源任务的排序优势是有范围的表示发现，而非跨任务机制已成立。

目标不是证明“加关系网络一定更好”，而是形成有反例、有干预、有新对象预测的结论。若修正后的强基线轻易解决问题，应诚实写成边界，不再抬高测试难度维持失败率。
