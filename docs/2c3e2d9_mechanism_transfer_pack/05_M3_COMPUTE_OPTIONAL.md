# M3｜独立备选：同一观测信息，计算放在哪里才有用？

这是允许大胆探索的第三选择，不是强制把全文扩成三个故事。它利用已有N02大效应，不重复48臂网格。

## 问题

64→224上采样没有新信息，却有大J增益；已有比较同时改变12.25×卷积MAC。要区分训练计算更多、推理空间网格更密、早期下采样方式、有效对象分辨率。

## 最小比较

选择同一稳定ResNet18和已验证bank：
- A：64标准；
- B：64上采样224标准（旧锚）；
- C：64标准，增加训练更新，使总训练MAC匹配B；
- D：64保留早期网格的模型，通过宽度/后期块预算与B匹配推理MAC；
- E（仅条件探索）：RGB可见对象局部采样/ROI，附全局位置编码，与B匹配推理MAC，不用oracle定位。

不能同时精确匹配所有资源时，分别给训练成本前沿与推理成本前沿，不宣称“完全公平”。数据/parent曝光、更新次数、MAC、wall time、显存分别记录。

先FP32源锚。mask必须面积保真，不能把采样丢线问题当成机制；小编辑切片要在看模型结果前确保有足够独立parent，不能重复原来5quartet/3parent切片。

## 读法

若C追平B，优先写计算预算/优化解释。
若D/E在相同推理预算更好，而且在独立观测风格复现，可形成“空间计算分配影响变化可靠性”的结果。
若只是static与flip同比提高，不写composition专属机制。
若A/B优势依赖预训练与否，分层报告，不平均为通用定律。

## 升级要求

用一个模型大小或观测扰动作事先预测，而不是再找最佳分辨率。该方向只有在能排除主要资源混杂时才进正文；否则作为计算敏感性附录。
